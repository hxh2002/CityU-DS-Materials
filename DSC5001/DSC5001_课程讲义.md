## 0.1 先建立一个观念：公式是一句压缩过的句子

统计学习里的公式通常不是为了“炫技”，而是把一段重复规则压缩成一行。例如
$\bar{x} = (1/n)\sum_{i}x_{i}$，只是在说：把 n 个数加起来，再除以
n。矩阵公式 $\hat{\beta} = (X^{\top}X)^{-1}X^{\top}y$
也不是神秘咒语，它只是“找到最能让预测接近 y 的那组系数”的一种封闭写法。

读公式要像读句子：先看它把哪些“主谓宾”压缩掉了。压缩牺牲了一部分直觉，换来“一行顶一页”的表达力。本章的目的，就是把这些被压缩掉的约定俗成符号，以及微积分、线性代数、概率论的基础，一次性摊开讲清楚。后续五周出现的几乎每个符号，都能在本章找到出处。

> **抓住主线 Key Idea｜读公式的四步法**
>
> 先找“谁是结果”；再找“输入是什么”；然后把 $\sum$、$\prod$、$^{\top}$、$^{-1}$
> 等操作逐个翻译；最后问这个结果在统计上回答什么问题。不要一上来就试图把整行同时理解。

### 0.2.1 数字集合：$\mathbb{N}$、$\mathbb{Z}$、$\mathbb{R}$、$\mathbb{R}^{n}$ 差在哪

这四个符号最容易混，因为长得像，装的却是完全不同的东西。一句话区分：**看它装的是“整数还是实数”“一个数还是一串数”。**

| 符号                                                                                                                                          | 装什么                       | 例子                                                                   | 本课程用途 |
| --------------------------------------------------------------------------------------------------------------------------------------------- | ---------------------------- | ---------------------------------------------------------------------- | ---------- |
| $\mathbb{N}$                          | 自然数$0,1,2,3,\ldots$           | 样本量$n=100$                                                | 计数：样本个数、实验次数     |                                                                        |            |
| $\mathbb{Z}$                          | 整数$\ldots,-1,0,1,2,\ldots$     | 差值$-3$                                                     | 编号、计数、正负变化         |                                                                        |            |
| $\mathbb{R}$                          | 一个实数（可含小数、负数、无理数） | 身高$172.5$           | 单个观测值，如$x_{i}\in\mathbb{R}$ |                              |                                                                        |            |
| $\mathbb{R}^{n}$ / $\mathbb{R}^{d}$                                                                                                       | $n$ 个实数排成一列（向量） | $[172.5,\ 65]^{\top}$ | 一个样本的多个特征，如$y\in\mathbb{R}^{n}$ |            |

三点关键区别：

- **有没有上标**：$\mathbb{R}$ 是“一个数”；$\mathbb{R}^{n}$ 是“$n$ 个数组成的一个向量”。所以 $x_{i}\in\mathbb{R}$ 指某一次观测的单个数值，而 $y\in\mathbb{R}^{n}$ 是把 $n$ 个响应值打包成一根向量。
- **$n$ 和 $d$ 分别是什么**：本课程里 $n$ = 观测个数（样本量，矩阵的行数），$d$ = 特征个数（列数）。于是 $\beta\in\mathbb{R}^{d}$ 表示有 $d$ 个回归系数，$y\in\mathbb{R}^{n}$ 表示有 $n$ 个响应值。写 $\mathbb{R}^{d}$ 比逐个列出 $(\beta_{1},\ldots,\beta_{d})$ 更省事。
- **整数 vs 实数**：$\mathbb{N}$、$\mathbb{Z}$ 只装整数，常用于计数和下标；$\mathbb{R}$、$\mathbb{R}^{n}$ 允许小数，用来装真实测量值（身高、价格这些几乎都不是整数）。

> **易错点 Common Pitfall｜别把 $\mathbb{R}$ 和 $\mathbb{R}^{n}$ 当成同一个东西**
>
> 看到 $\mathbb{R}$ 就知道是“一个数”，看到 $\mathbb{R}^{n}$ 就知道是“一根长度为 $n$ 的向量”。$\mathbb{R}^{1}$ 等价于 $\mathbb{R}$（只含一个数的向量）；$n=0$ 没有意义。$\mathbb{R}^{n}$ 里的数也不要求是整数。

> **直觉 Intuition｜大写与小写是“观察前 / 观察后”的区分**
>
> 本课程严格区分 $X$（随机变量，取值还没定）与 $x$（观测值，具体数字）。同理 $\hat{\theta}$ 是估计量（规则），而算出来的那个数叫估计值。很多“看不懂”其实来自把大小写当成了同一样东西。

## 0.3 Summation 求和与 Product 连乘

*为什么讲这节？* 期望、残差平方和、似然都要用 $\sum$（相加）与 $\prod$（相乘）写成，第 1–4 章的公式几乎都离不开它们。

### 0.3.1 Summation 求和

Summation 求和符号 $\sum$ 用来表示“把很多类似的项加起来”。

$$
\sum_{i=1}^{n} x_{i} = x_{1} + x_{2} + \cdots + x_{n}
$$

下标 $i=1$ 表示从第 1 项开始，上标 n 表示到第 n 项结束。字母 $i$ 叫 Dummy Index 哑指标：它只是循环用的临时名字，$\sum_{i}x_{i}$ 与 $\sum_{j}x_{j}$ 完全等价。若上下限一目了然，也常简写成 $\sum_{i}x_{i}$。

求和有三条最常用的性质：

$$
\sum_{i}(a_{i}+b_{i}) = \sum_{i}a_{i}+\sum_{i}b_{i}, \qquad
\sum_{i}c\,a_{i} = c\sum_{i}a_{i}, \qquad
\sum_{i=1}^{n}1 = n
$$

第一条说“和的求和等于求和再相加”；第二条说常数可以提到外面；第三条说明“把 1 加 n 次得到 n”。

双重求和 $\sum_{i}\sum_{j}a_{ij}$ 就是“对每一行、每一列都加一遍”。回归里的 $\sum_{i}(y_{i}-x_{i}^{\top}\beta)^{2}$ 就是把每个样本的平方残差逐个加起来。两个顺手记住的封闭公式（第 5 周次数、组合计数会用到）：

$$
\sum_{i=1}^{n}i = \frac{n(n+1)}{2}, \qquad
\sum_{i=1}^{n}c = nc
$$

例如数据 $[2,3,5]$，$\sum_{i}x_{i} = 2+3+5 = 10$；样本均值 Sample Mean 就是 $\bar{x} = 10/3$。用 $\sum$ 写出来，$\bar{x}=(1/n)\sum_{i}x_{i}$，分母 n 与求和一起工作，得到“平均数”。

### 0.3.2 Product 连乘

Product 连乘符号 $\prod$
同理，只是把“加”换成“乘”。Likelihood 似然中经常出现
$\prod$，因为独立观测的联合概率要相乘。

$$
\prod_{i=1}^{n} p(x_{i}\mid \theta) = p(x_{1}\mid \theta)p(x_{2}\mid \theta)\cdots p(x_{n}\mid \theta)
$$

逐项翻译：下标 $i=1$ 到 $n$，把每个样本的 $p(x_{i}\mid \theta)$ 依次相乘。小算例：数据 $[2,3,5]$，则 $\prod_i x_i = 2\times3\times5=30$。

连乘有三条与求和不同、最容易混的规则：

$$
\prod_{i}(c\,a_{i}) = c^{\,n}\prod_{i}a_{i}, \qquad
\prod_{i}(a_{i}b_{i}) = \Big(\prod_{i}a_{i}\Big)\Big(\prod_{i}b_{i}\Big), \qquad
\prod_{i}(a_{i}+b_{i}) \ne \prod_{i}a_{i} + \prod_{i}b_{i}
$$

即：常数提到 $\prod$ 外面要变成 $n$ 次方（提到 $\sum$ 外面则不用变）；乘积可以拆开（对应 $\sum$ 的加法可拆）；但“和的连乘”不等于“连乘的和”，$\prod$ 不能像 $\sum$ 那样逐项分配。

连乘还有个麻烦：当 n 很大时，一串小于 1 的概率相乘会迅速趋近于 0（Numerical Underflow 数值下溢；注意连续密度值可以大于 1，但多个相乘后仍可能很小）；而且乘法求导不如加法方便。这正是第 2 章 MLE 要取对数（Log-Likelihood）的原因：

$$
\operatorname{log}\!\left(\prod_{i}p_{i}\right) = \sum_{i}\operatorname{log}p_{i}
$$

连乘被翻译成了连加。这个“乘积转和”的技巧会反复出现。

> **易错点 Common Pitfall｜求和与连乘不能互换**
>
> $\sum$ 是加法、$\prod$ 是乘法；联合分布用 $\prod$（概率相乘），期望、RSS 用 $\sum$（项相加）。看到 $\prod$ 却当成 $\sum$，是初学最常见的一类错误。

## 0.4 Function 函数、Input 输入与 Output 输出

*为什么讲这节？* 模型本质上就是函数：输入特征、输出预测；后面的回归函数 $m(x)$、特征映射 $\phi(x)$ 都只是它的特例。

Function 函数可以理解为“输入一个东西，按固定规则加工，输出一个东西”。例如
$f(x)=1+x^{2}$：输入 $x=2$，输出 5。机器学习模型本质上也是函数：输入
Features 特征，输出 Prediction 预测。

| 写法                                              | 直觉                                                            |
| ------------------------------------------------- | --------------------------------------------------------------- |
| $f(x)$                                          | 把 x 放进函数 f 后得到的输出                                    |
| $f(x_{0})$ | 在某个特定输入$x_{0}$ 处的输出   |                                                                 |
| $f'(x)$                                         | 函数在 x 处的瞬时斜率/变化率                                    |
| $f\circ g$ | 复合函数：先 g 后 f，即$f(g(x))$ |                                                                 |
| $\phi(x)$                                       | Feature Map 特征映射：把原输入变成一组新特征                    |
| $T(D)$                                          | Statistic/Estimator 统计量或估计规则：把整份数据 D 变成一个结果 |
| $\mathbf{1}\{A\}$                               | Indicator Function 指示函数：事件 A 发生取 1，否则取 0          |

关于 Definition Domain 定义域：函数只在“允许的输入范围”内有效。log 只能喂正数、$\sqrt{\cdot}$ 只能喂非负数、方差公式里不能除以 0——这些限制在推导 MLE 时必须留意。

> **直觉 Intuition｜“函数”与“映射”是同一件事的两种叫法**
>
> 线性代数里把 $x\mapsto X\beta$ 叫 Linear Map 线性映射，统计里把 $x\mapsto m(x)$ 叫 Regression Function 回归函数，本质都一样：一个把输入转成输出的规则。$\phi(x)$ 只是“先把原始输入改写成一串新特征，再走规则”。

## 0.5 Power 幂、Exponential 指数与 Logarithm 对数

*为什么讲这节？* 高斯密度的核心是 $e^{z}$，极大似然要取对数把连乘变连加；不认识 $e$ 与 $\log$，第 1、2 章的公式就读不动。

### 0.5.1 Power 幂

$x^{2}$ 是 $x\times x$，$x^{3}$ 是 $x\times x\times x$。幂运算有三条常用法则：

$$
x^{a}x^{b}=x^{a+b}, \qquad (x^{a})^{b}=x^{ab}, \qquad x^{-a}=\frac{1}{x^{a}}
$$

其中 $x^{0}=1$（任何非零数的 0 次幂都是 1），$x^{1/2}=\sqrt{x}$。多项式回归 $x,x^{2},\ldots ,x^{d}$ 就是把这些幂当成新特征。

### 0.5.2 Exponential 指数函数

指数函数 $\operatorname{exp}(z)=e^{z}$ 在 Gaussian Distribution 高斯分布里大量出现。这里 $e$ 是自然常数 Euler’s Number：

$$
e \approx 2.718281828\ldots
$$

它是一个固定数字，就像 $\pi$ 一样，不需要“算出来”才能用。几个必须记住的点值：

$$
\operatorname{exp}(0)=1, \qquad \operatorname{exp}(1)=e\approx 2.718, \qquad \operatorname{exp}(-1)\approx 0.368
$$

并且 $z\to +\infty$ 时 $e^{z}\to +\infty$，$z\to -\infty$ 时 $e^{z}\to 0$，$e^{z}$ 永远为正、单调递增。指数法则与幂法则一致：

$$
e^{a+b}=e^{a}e^{b}, \qquad (e^{a})^{b}=e^{ab}, \qquad e^{-a}=1/e^{a}
$$

为什么偏偏用 $e$ 做底？因为只有以 $e$ 为底时，指数函数的导数才等于它自己：

$$
\frac{d}{dz}e^{z} = e^{z}
$$

这个“求导不变”的性质让指数函数在微积分里极其好处理，也是高斯分布求 MLE 时能顺利化简的关键。

### 0.5.3 Logarithm 对数

Logarithm 对数 log 是指数的反函数。定义很简单：$\operatorname{log} a$ 回答“e 要乘方几次才等于 a”，即

$$
\operatorname{log}(e^{z})=z, \qquad e^{\operatorname{log} a}=a \quad (a>0)
$$

常用对数法则（把它当成“把乘除降级为加减”的工具）：

$$
\operatorname{log}(ab) = \operatorname{log} a + \operatorname{log} b, \qquad
\operatorname{log}\!\left(\frac{a}{b}\right) = \operatorname{log} a - \operatorname{log} b, \qquad
\operatorname{log}(a^{k}) = k\operatorname{log} a
$$

底数不同只差一个常数因子。工程上 $\log_{2}$ 常见于信息论（bit），$\log_{10}$ 常见于分贝，但统计里默认 $\operatorname{log}=\ln=\log_{e}$。底数换了，最大值的位置不变，所以“用哪个底”对 MLE 没有影响。

> **直觉 Intuition｜为什么 MLE 总要取 log？**
>
> Likelihood 似然通常是很多小概率/密度的连乘。取 Log-Likelihood
> 对数似然后，连乘变求和，既更好算，也更不容易出现数值下溢；而 log
> 单调递增，所以最大值的位置不变。

> **易错点 Common Pitfall｜log 的符号**
>
> 由于 $\operatorname{log}1=0$，所以 $a>1$ 时 $\operatorname{log} a>0$，$0<a<1$ 时 $\operatorname{log} a<0$。对小于 1 的概率取对数会得到负数——看到负的对数似然不必惊慌，那只是“概率小于 1”的正常结果。

## 0.6 Derivative 导数：把它理解成“局部斜率”

*为什么讲这节？* 所有“最小化/最大化”的估计都要用导数找驻点，第 2 章 MLE、第 4 章 OLS 都建立在这上面。

Derivative 导数 $f'(x)$ 描述 x 轻微变化时 $f(x)$ 变化得有多快。严格定义是差商的极限：

$$
f'(x) = \lim_{h\to 0}\frac{f(x+h)-f(x)}{h}
$$

不用纠结极限的严格性，只要记住：它是曲线在该点的切线斜率、也就是“瞬时变化率”。直线 $f(x)=a+bx$ 的导数恒为 b，所以直线的斜率处处相同；二次函数 $f(x)=x^{2}$ 的导数是 2x，所以斜率会随 x 改变。第 5 周说“直线无法表达斜率变化”，本质就在这里。

小算例：$f(x)=x^{2}$ 在 $x=3$ 处 $f'(3)=6$，意思是 x 从 3 稍微增加一点，$f$ 大约以 6 倍的速度增加——例如 x 从 3 变到 3.01，$f$ 就从 9 变到约 9.06。注意导数给的是“切线斜率”（局部近似的变化率），不是变化量本身。

| 函数            | 导数                                       | 记忆                       |
| --------------- | ------------------------------------------ | -------------------------- |
| c               | 0                                          | 常数不变                   |
| x               | 1                                          | x 每增加一点，自己同样增加 |
| $x^{2}$       | 2x                                         | 平方的斜率随 x 改变        |
| $x^{3}$       | $3x^{2}$                                 | 三次项更弯                 |
| $x^{n}$       | $nx^{n-1}$                               | 幂法则（n 为常数）         |
| $1/x$         | $-1/x^{2}$ | 即$x^{-1}$ 的幂法则       |                            |
| $\sqrt{x}$    | $1/(2\sqrt{x})$ | 即$x^{1/2}$ 的幂法则 |                            |
| log x           | 1/x                                        | MLE 推导常见               |
| exp(x)          | exp(x)                                     | 指数函数导数还是自己       |
| $af(x)+bg(x)$ | $af'(x)+bg'(x)$                          | 线性性：可以逐项求导       |

除了逐项求导，还要会用三条组合法则：

$$
(fg)'=f'g+fg' \quad(\text{乘}), \qquad
\left(\frac{f}{g}\right)'=\frac{f'g-fg'}{g^{2}} \quad(\text{除}), \qquad
\frac{d}{dx}f(g(x))=f'(g(x))\,g'(x) \quad(\text{Chain Rule 链式法则})
$$

链式法则在 MLE 里无处不在。例如对 $\operatorname{log}(1-p)$ 求导：外层是 log，内层是 $1-p$，于是

$$
\frac{d}{dp}\operatorname{log}(1-p)=\frac{1}{1-p}\cdot(-1)=-\frac{1}{1-p}
$$

二阶导数 $f''(x)$ 描述“斜率本身的变化”，它决定曲线的弯曲方向：$f''>0$ 是 Convex 凸（开口向上，像碗），$f''<0$ 是 Concave 凹（开口向下，像山）。判断一个驻点是最大还是最小，就看二阶导的符号。

## 0.7 Partial Derivative 偏导数、Gradient 梯度与 Hessian 黑塞矩阵

*为什么讲这节？* 参数往往不止一个，求极值要用偏导数组成梯度；判断找到的是最大还是最小，要看 Hessian。第 2 章 MLE 与第 4 章正规方程都从这里出发。

当函数有多个未知量，例如
$\operatorname{RSS}(\beta_{0},\beta_{1})$，Partial Derivative
偏导数就是“只让其中一个变量动，其他先固定”。写法上用 $\partial$ 区别于一元导数 $d$：

$$
\frac{\partial f}{\partial x_{j}} = \lim_{h\to 0}\frac{f(\ldots ,x_{j}+h,\ldots )-f(\ldots ,x_{j},\ldots )}{h}
$$

逐项翻译：$\partial f/\partial x_{j}$ 读作“把除 $x_{j}$ 以外的变量都当常数，只对 $x_{j}$ 求导”。小算例：$f(x_{1},x_{2})=x_{1}^{2}x_{2}$，对 $x_{1}$ 求偏导时把 $x_{2}$ 看成常数，得 $\partial f/\partial x_{1}=2x_{1}x_{2}$；对 $x_{2}$ 求偏导时把 $x_{1}$ 看成常数，得 $\partial f/\partial x_{2}=x_{1}^{2}$。

Gradient 梯度 $\nabla$ 把所有偏导数组成一个向量，指向函数上升最快的方向：

$$
\nabla f = \left[\frac{\partial f}{\partial x_{1}},\ldots ,\frac{\partial f}{\partial x_{p}}\right]^{\top}
$$

小算例：$f(x_{1},x_{2})=x_{1}^{2}+x_{2}^{2}$，则 $\nabla f=[2x_{1},2x_{2}]^{\top}$。在点 $(1,2)$ 处 $\nabla f=[2,4]^{\top}$，它指向“从这里往上爬最陡”的方向；在原点 $\nabla f=[0,0]^{\top}$，那里正是 $f$ 的最低点。

很多估计问题都在找一个最低点或最高点；在光滑的内部最优点，每个方向的坡度都必须为零，所以

$$
\nabla f(\hat{x})=0
$$

这组方程也叫 First-Order Condition 一阶条件。最小化
$\operatorname{RSS}(\beta)$ 等价于令 $\nabla_{\beta}\operatorname{RSS}(\hat{\beta}) = 0$，这就是 OLS Normal Equations 正规方程的来源。

> **易错点 Common Pitfall｜不要把“导数=0”当成万能答案**
>
> 导数为 0 只给出 Stationary Point
> 驻点。还要判断它是最大、最小还是平坦点。Bernoulli MLE
> 里课件用二阶导数为负说明 Log-Likelihood 对数似然是 Concave
> 凹的，因此驻点是最大值。

### 0.7.1 判定极值：二阶条件与 Hessian 黑塞矩阵

把全部二阶偏导数堆成一个矩阵，就是 Hessian 矩阵：

$$
H = \nabla^{2}f =
\begin{bmatrix}
\dfrac{\partial^{2}f}{\partial x_{1}^{2}} & \cdots & \dfrac{\partial^{2}f}{\partial x_{1}\partial x_{p}}\\
\vdots & \ddots & \vdots\\
\dfrac{\partial^{2}f}{\partial x_{p}\partial x_{1}} & \cdots & \dfrac{\partial^{2}f}{\partial x_{p}^{2}}
\end{bmatrix}
$$

判定规则（只需会用，不必证明）：

| 条件                           | 结论                        |
| ------------------------------ | --------------------------- |
| $f''(x)>0$（一元）           | 极小值                      |
| $f''(x)<0$（一元）           | 极大值                      |
| Hessian 正定 Positive Definite | 极小值（多元版“碗”）      |
| Hessian 负定 Negative Definite | 极大值（多元版“山”）      |
| Hessian 不定                   | 鞍点 Saddle Point，不是极值 |

小算例：$f(x_{1},x_{2})=x_{1}^{2}+x_{2}^{2}$ 的 Hessian 是 $\begin{bmatrix}2&0\\0&2\end{bmatrix}$，主对角元都为正、矩阵正定，所以原点处取极小值。

例如 RSS 的 Hessian 是 $2X^{\top}X$，而 $X^{\top}X$ 在列满秩时是 Positive Definite 正定的，所以 OLS 解一定是全局最小值，而不可能是最大值或鞍点。

> **抓住主线 Key Idea｜Convex 凸函数为什么受宠**
>
> 若函数在定义域上处处 $f''\ge 0$（多元则是 Hessian Positive Semi-Definite 半正定），它就是 Convex 凸函数。凸函数最重要的性质是：局部最小值就是全局最小值，而且驻点唯一时解也唯一。OLS 的 RSS 正是这种“好函数”，所以 $(X^{\top}X)^{-1}X^{\top}y$ 能一步给出全局最优。

## 0.8 Vector 向量：把一串数当成一个对象

*为什么讲这节？* 把一条样本的特征写成一个向量，回归公式才能紧凑地写成 $x^{\top}\beta$（第 4 章）。

Vector 向量可以看成有顺序的一列数。一个房子的 Features 特征可能是
$x=(1,\text{面积},\text{房龄},\text{距地铁距离})^\top$。最前面的 1
常用来承载 Intercept 截距。

$$
x = [1, x_{1}, x_{2}, \ldots , x_{p}]^{\top}
$$

### 0.8.1 向量的基本运算

$$
\text{加法：}(u+v)_{j}=u_{j}+v_{j}, \qquad
\text{数乘：}(cu)_{j}=c\,u_{j}, \qquad
\text{Dot Product 点积：}u^{\top}v=\sum_{j}u_{j}v_{j}
$$

Dot Product 点积
$x^{\top}\beta = \sum_{j}x_{j}\beta_{j}$，就是“每个特征乘自己的权重，再全部加起来”。因此多元线性回归
$E[Y\mid X=x]=x^{\top}\beta$ 并不比
$\beta_{0}+\beta_{1}x_{1}+\ldots +\beta_{p}x_{p}$ 更神秘，只是写得更短。

点积还有几何意义。它等于“两向量长度乘以夹角的余弦”，即

$$
u^{\top}v = \lVert u\rVert\,\lVert v\rVert\cos\theta
$$

于是：点积为 0 表示两向量垂直（Orthogonal 正交）；点积为正表示同向；为负表示反向。第 4 周“残差与特征正交”用的就是这条性质。

### 0.8.2 线性组合、张成空间与线性无关

把向量乘上系数再加起来，叫 Linear Combination 线性组合：

$$
c_{1}x_{1}+c_{2}x_{2}+\cdots +c_{p}x_{p}
$$

所有可能的线性组合构成的集合叫 Span 张成空间。如果其中某个向量能由其它向量拼出来（如 $x_{2}=2x_{1}$），就说这些向量 Linearly Dependent 线性相关；反之叫 Linearly Independent 线性无关。线性无关向量的最大个数就是维数，也决定了矩阵的 Rank 秩。

小算例：在平面里，$x_{1}=(1,0)$ 与 $x_{2}=(0,1)$ 无法互相拼出，线性无关，它们的张成空间是整个平面；而 $x_{1}=(1,2)$ 与 $x_{2}=(2,4)=2x_{1}$ 线性相关，张成空间只是过原点的一条直线——多出的那个向量没有带来新方向。

> **直觉 Intuition｜为什么回归需要“独立的方向”**
>
> 每个特征就像模型提供的一个“独立方向”。如果两个特征说的是同一件事（$x_{2}=2x_{1}$），它们其实只贡献了一个方向，模型就无法把两个系数分开——这就是第 4 周 Perfect Multicollinearity 完全多重共线性与 $X^{\top}X$ 不可逆的几何来源。

## 0.9 Matrix 矩阵：把很多样本整齐地堆起来

*为什么讲这节？* 整份数据集就是一个设计矩阵 X；第 4 章的 OLS 解 $\hat{\beta}=(X^{\top}X)^{-1}X^{\top}y$ 完全用矩阵语言写成。

在碰矩阵运算之前，先用大白话把“我们到底在算什么、X/β/y/β̂ 各是谁”摆清楚——否则公式里的字母会像陌生人。

**① 回归（Regression）在做什么？** 一句话：**给一组输入 x，预测一个数值 y**。例如“广告费 100 元 → 销量大概多少件”“房子 80 平米、房龄 5 年 → 价格大概多少”。它预测的是**条件平均**（给定 x 时 y 平均是多少），不是某个确定的未来值：

$$
E[Y\mid X=x]=m(x)
$$

**② 一条数据长什么样？** 第 i 条数据是一对 $(x_i,\ y_i)$：$x_i$ 是这个样本的特征（输入），$y_i$ 是它的响应（要预测的那个数）。例如第 3 周广告费 $x_3=80$ 元、实际销量 $y_3=21$ 件。数据共 $n$ 条，记 $i=1,\ldots,n$。

**③ 五个主角，一句话各一个：**

| 记号            | 名字                     | 用最白的话说                                                                     | 已知 / 未知                |
| --------------- | ------------------------ | -------------------------------------------------------------------------------- | -------------------------- |
| $y$           | Response Vector 响应向量 | **你观测到的答案**：把 $n$ 个 $y_i$ 竖着摞成一列                       | 已知（数据）               |
| $X$           | Design Matrix 设计矩阵   | **你手里的输入表**：一行一个样本、一列一种特征，第一列全为 1（给截距占位） | 已知（数据）               |
| $\beta$       | 真实系数                 | **模型背后的真相**：每个特征该乘多少的“正确”权重                         | **未知，永远不知道** |
| $\varepsilon$ | Error 误差/噪声          | 答案相对“真实平均”的随机偏离，通常算不出                                       | 未知                       |
| $\hat{\beta}$ | 估计系数                 | 用数据**猜**出来的那组权重（“帽子 = 估计”，见 ④）                       | 可计算                     |

把“预测 = 每个特征乘自己的权重，再全部加起来”打包成一行，就是本节中心的矩阵公式 $y=X\beta+\varepsilon$（下面正式给出）。

**④ 帽子（hat）是什么意思？** 一条规则记一辈子：**带帽子 = “由数据算出来的估计 / 拟合版本”。** 真相 $\beta$ 不知道，就用数据猜一个最像它的 $\hat{\beta}$（读“beta-hat”）。由 $\hat{\beta}$ 再长出两个同样带帽子的量：

$$
\hat{y}=X\hat{\beta}\ \ (\text{拟合值 / 预测值}),\qquad e=y-\hat{y}\ \ (\text{Residual 残差})
$$

$\hat{\beta}$ 怎么求？——让“预测 $\hat{y}$ 与真实 $y$ 的差距”最小，也就是把残差平方和压到最小（这正是 0.10 的主角）：

$$
\hat{\beta}=\arg\min_{\beta}\ \lVert y-X\beta\rVert^{2}
$$

> **易错点 Common Pitfall｜$\beta$ 是真相，$\hat{\beta}$ 是猜测，别混**
>
> $\beta$ 是总体里**固定但未知**的真实权重，换一批数据它不变；$\hat{\beta}$ 是用样本**算出来**的估计，换一批数据它就会变。同理 $y$（真实观测）≠ $\hat{y}$（模型预测），$\varepsilon$（相对真实均值的误差，算不出）≠ $e$（相对拟合均值的残差，能算出）。

**⑤ 用贯穿本讲义的小数据把它落地：** 3 周数据，广告费 $x=[1,2,3]$，销量 $y=[2,3,5]$。写成矩阵就是

$$
X=\begin{bmatrix}1&1\\1&2\\1&3\end{bmatrix},\qquad y=\begin{bmatrix}2\\3\\5\end{bmatrix},\qquad \beta=\begin{bmatrix}\beta_0\\\beta_1\end{bmatrix}\ (\text{真相，我们看不到})
$$

由最小二乘可算出 $\hat{\beta}_0=\tfrac13$、$\hat{\beta}_1=\tfrac32$，即拟合线 $\hat{y}=\tfrac13+\tfrac32 x$（第 4 章正式推导）。这组 $x=[1,2,3]$、$y=[2,3,5]$ 会在整份讲义里反复出现，先记住它。

Matrix 矩阵是二维数字表。Design Matrix 设计矩阵 X
的每一行是一条样本，每一列是一种特征。Response Vector 响应向量 y
把所有目标值竖着排起来。

$$
y = X\beta + \varepsilon
$$

n 个样本 $\times d$ 个系数，一次写完。

| 对象       | 常见维度       | 含义                             |
| ---------- | -------------- | -------------------------------- |
| X          | $n \times d$ | n 个样本、d 个系数对应的特征矩阵 |
| $\beta$  | $d \times 1$ | 系数向量                         |
| y          | $n \times 1$ | 响应/目标                        |
| ε         | $n \times 1$ | 误差/噪声                        |
| $X\beta$ | $n \times 1$ | 模型对全部样本的均值预测         |

### 0.9.1 矩阵乘法到底怎么算

矩阵相乘的规则是“左矩阵的第 i 行 点积 右矩阵的第 j 列”，得到结果矩阵的第 $(i,j)$ 个元素：

$$
(AB)_{ij} = \sum_{k} A_{ik}B_{kj}
$$

以回归中最常见的 $X\beta$ 为例，$X$ 是 $n\times d$、$\beta$ 是 $d\times 1$，结果是一个 $n\times 1$ 向量，第 i 个分量正好是 $x_{i}^{\top}\beta$，也就是对第 i 个样本的预测。

小算例：$\begin{bmatrix}1&2\\3&4\end{bmatrix}\begin{bmatrix}1\\1\end{bmatrix}=\begin{bmatrix}1\cdot1+2\cdot1\\3\cdot1+4\cdot1\end{bmatrix}=\begin{bmatrix}3\\7\end{bmatrix}$——结果第 1 个分量是“左矩阵第 1 行”与右向量点积，第 2 个分量同理。判断乘法能否做，只看“左列数 = 右行数”是否相等。

也可以换个视角看 $X\beta$：它是 X 各个列向量的线性组合，权重就是 $\beta$ 的分量。这正是“预测值一定落在 X 的列空间里”的原因。

三条必须记住的性质：

$$
AB \ne BA\ (\text{一般不交换}), \qquad (AB)C=A(BC)\ (\text{可结合}), \qquad A(B+C)=AB+AC\ (\text{可分配})
$$

矩阵乘法不满足交换律，是它和普通数字最大的区别。

### 0.9.2 单位矩阵与转置

Identity Matrix 单位矩阵 $I$ 对角线为 1、其余为 0，作用像数字里的 1：$AI=IA=A$。

Transpose 转置 $A^{\top}$ 就是把行和列交换，$(A^{\top})_{ij}=A_{ji}$。它满足

$$
(A^{\top})^{\top}=A, \qquad (A+B)^{\top}=A^{\top}+B^{\top}, \qquad (AB)^{\top}=B^{\top}A^{\top}
$$

最后一条“乘积转置要倒序”很关键。当 A 是 Symmetric Matrix 对称矩阵时 $A^{\top}=A$，例如 $X^{\top}X$ 永远是对称的。

### 0.9.3 行列式与可逆性

Determinant 行列式 $\det(A)$ 是一个数字，衡量矩阵对空间的“体积缩放倍数”。2×2 时有现成公式：

$$
A=\begin{bmatrix}a&b\\c&d\end{bmatrix}
\quad\Rightarrow\quad
\det(A)=ad-bc
$$

行列式只对方阵（行数 = 列数）才有定义；对一个方阵，它有一个决定性作用：$\det(A)=0$ 时不可逆（Singular 奇异），$\det(A)\ne 0$ 时存在逆矩阵。几何上，$\det=0$ 意味着 A 的列向量线性相关——它们被“压”到了比原来更低维的空间里（平面里塌成一条线、空间中塌成一个平面），信息丢掉了，无法还原。非方阵没有行列式、也没有通常意义的逆矩阵，但仍可以谈秩与列空间。

### 0.9.4 逆矩阵

Inverse 逆矩阵 $A^{-1}$ 类似标量里的 $1/a$：若 $A^{-1}A=AA^{-1}=I$，就能把 A “消掉”。2×2 的逆有现成公式：

$$
A^{-1}=\frac{1}{ad-bc}\begin{bmatrix}d&-b\\-c&a\end{bmatrix}
$$

两个常用性质：

$$
(AB)^{-1}=B^{-1}A^{-1}, \qquad (A^{\top})^{-1}=(A^{-1})^{\top}
$$

注意同样“倒序”。但不是每个矩阵都有逆——只有**方阵**且 $\det(A)\ne 0$ 时才可逆；对方阵来说，$\det\ne 0$ 等价于它满秩（各列线性无关）。

小算例：$A=\begin{bmatrix}1&2\\3&4\end{bmatrix}$，$\det=1\cdot4-2\cdot3=-2\ne 0$，所以可逆，$A^{-1}=\frac{1}{-2}\begin{bmatrix}4&-2\\-3&1\end{bmatrix}=\begin{bmatrix}-2&1\\1.5&-0.5\end{bmatrix}$。

> **直觉 Intuition｜为什么 $X^{\top}X$ 可能不可逆？**
>
> 如果一列特征能由其他列完全拼出来，例如
> $x_{2}=2x_{1}$，那么两列没有提供两份独立信息，称为 Perfect
> Multicollinearity 完全多重共线性。此时 $X^{\top}X$ 的行列式为 0，不可逆，系数可能不唯一。

### 0.9.5 秩与 $X^{\top}X$

Rank 秩衡量列向量里有多少真正独立的信息。对 $n\times d$ 的 X：

| 情形                         | 含义                     | 对 OLS 的影响                            |
| ---------------------------- | ------------------------ | ---------------------------------------- |
| $\operatorname{rank}(X)=d$ | 列满秩（各列线性无关）   | $X^{\top}X$ 可逆，$\hat{\beta}$ 唯一 |
| $\operatorname{rank}(X)<d$ | 列线性相关（存在共线性） | $X^{\top}X$ 不可逆，系数不唯一         |

$X^{\top}X$ 这个 $d\times d$ 对称矩阵有时也叫 Gram Matrix 格拉姆矩阵。它的对角元是“每个特征自身的平方和”，非对角元是“两个特征的内积”，所以它同时记录了尺度与特征之间的重叠——这正是 0.15 节拆解 OLS 公式时要用的直觉。

## 0.10 解线性方程组与 Least Squares 最小二乘的几何

*为什么讲这节？* 这是第 4 周线性回归的心脏：用几何投影解释正规方程为什么长那样，$\hat{\beta}=(X^{\top}X)^{-1}X^{\top}y$ 就从这里自然长出来。

把回归写成矩阵形式 $y=X\beta+\varepsilon$。**如果先忽略误差**，问题就是解线性方程组 $X\beta=y$。本节把“解方程 → 找不到精确解 → 退而求最近 → 投影 → 正交 → 正规方程”这条链条从头到尾摊开讲；你用到的全部前置（线性方程组、向量长度、正交、极小值）都现补在本节里，不必先跳去别处。

> **抓住主线 Key Idea｜本节的一句话**
>
> 当 $X\beta=y$ 无精确解时，“最好的近似解”就是**把 $y$ 垂直投影到 $X$ 的列空间**；把这个几何动作翻译成代数，就得到正规方程 $X^{\top}X\hat{\beta}=X^{\top}y$，进而 $\hat{\beta}=(X^{\top}X)^{-1}X^{\top}y$。

### 0.10.1 前置①：什么是“线性方程组”，n 与 d 各是什么

先看最小的例子。一个特征、含截距、两个样本：

$$
\begin{cases}\beta_0+\beta_1\cdot1=2\\ \beta_0+\beta_1\cdot2=3\end{cases}
$$

这是关于两个**未知数** $\beta_0,\beta_1$ 的两条方程，写成矩阵就是 $X\beta=y$：

$$
X=\begin{bmatrix}1&1\\1&2\end{bmatrix},\qquad \beta=\begin{bmatrix}\beta_0\\\beta_1\end{bmatrix},\qquad y=\begin{bmatrix}2\\3\end{bmatrix}
$$

一般地：

- **未知数个数 $d$**：$\beta$ 有几个分量，就有几个待定系数（含截距）。
- **方程个数 $n$**：有几个样本，就有几条方程——每条样本都提出“预测应等于观测”。
- $X$ 是 $n\times d$，$y$ 是 $n\times1$。

**几何直觉（关键）**：每个方程在“$\beta$ 的空间”里是一条直线（高维时是超平面）。$n$ 条方程有没有公共交点，决定有没有精确解：

| 情形                                                                                        | 几何图像           | 结论                                         |
| ------------------------------------------------------------------------------------------- | ------------------ | -------------------------------------------- |
| $n=d$ 且各约束独立                                                                        | 两条直线交于一点   | **唯一精确解** $\beta=X^{-1}y$       |
| $n>d$（Overdetermined 超定）                                                              | 三条直线一般不共点 | **一般无精确解**，只能求“最接近的解” |
| $n<d$（Underdetermined 欠定） | 一条直线有无穷多点 | **无穷多解**，$\beta$ 不唯一 |                    |                                              |

> **注意 Note｜本课程几乎总在 $n>d$**
>
> 实际回归里样本数远多于特征数（$n\gg d$），总落在第二行：**精确解通常不存在**，这正是要引入最小二乘的原因。第一行是特例；第三行对应第 4 周的“秩不足 / 共线性”。

### 0.10.2 前置②：向量长度，以及“为什么用平方”

既然没有精确解，就要找“最接近 $y$”的预测。先补三个前置。

**（1）预测向量与残差向量。** 对任意一组系数 $\beta$，模型给出的预测是 $X\beta$（一个 $n$ 维向量，装着对每个样本的预测）。它与真实 $y$ 的差叫残差向量：

$$
e(\beta)=y-X\beta
$$

**（2）向量的长度（欧氏距离）。** 向量 $v=(v_1,\ldots,v_n)$ 的长度是

$$
\lVert v\rVert=\sqrt{v_1^2+\cdots+v_n^2}=\sqrt{\textstyle\sum_i v_i^2}
$$

这是勾股定理的高维版本（0.11 节展开）。$y$ 与 $X\beta$ 的**距离**就是残差的长度 $\lVert y-X\beta\rVert$。“最接近”就是让这个距离最小。

**（3）为什么可以改成最小化“距离的平方”。** 因为开方是单调的：距离最小 ⟺ 距离平方最小。平方去掉根号更好算，于是直接最小化

$$
\lVert y-X\beta\rVert^2=\sum_{i=1}^{n}(y_i-x_i^{\top}\beta)^2=\operatorname{RSS}(\beta)
$$

这就是 **Residual Sum of Squares 残差平方和**。**为什么用平方而不是直接把残差相加？** 残差有正有负，直接相加会抵消：$+4$ 与 $-4$ 相加为 0，却显然不是好拟合；平方让正负都变正，且对大偏差惩罚更重。

> **直觉 Intuition｜“最小二乘”这名字从哪来**
>
> “二乘”= 平方，“最小”= 让它最小——**Least Squares 就是让残差的平方和最小**。要求的系数记作 $\hat{\beta}=\arg\min_{\beta}\operatorname{RSS}(\beta)$（$\arg\min$ 返回“取得最小值的那个 $\beta$”，见 0.12）。

### 0.10.3 前置③：正交与投影

**（1）点积与垂直。** 点积 $u^{\top}v=\sum_j u_jv_j$（0.8 节）；点积为 0 当且仅当两向量 **正交（垂直）**：

$$
u^{\top}v=0 \quad\Longleftrightarrow\quad u\perp v
$$

**（2）投影的直觉。** 平面上“点到直线的最短连线”是**垂线**，垂足就是该点在直线上的投影。把“直线”换成高维子空间，“离 $y$ 最近的预测”就是 $y$ 在该子空间上的**正交投影**。本节把子空间取成 $X$ 的列空间。

### 0.10.4 几何图像：$X\beta$ 能取到的所有值构成“列空间”

$X\beta$ 是 $X$ 各列的线性组合，权重是 $\beta$ 的分量：

$$
X\beta=\beta_1\,(\text{第 1 列})+\beta_2\,(\text{第 2 列})+\cdots+\beta_d\,(\text{第 }d\text{ 列})
$$

$\beta$ 取遍所有可能值，$X\beta$ 扫过的集合就是各列的一切线性组合，称为 **Column Space 列空间** $\operatorname{Col}(X)$（回顾 0.8.2 的“张成空间”）。它的含义很直接：

> **$\operatorname{Col}(X)$ = 模型能产生的全部预测值的集合。**

于是“$X\beta=y$ 有没有解”等价于“**$y$ 在不在 $\operatorname{Col}(X)$ 里**”：在，就有精确解；不在（超定的常态），就在里面找离 $y$ 最近的点。

**把维数想清楚**：$\operatorname{Col}(X)$ 是 $\mathbb{R}^n$ 里的子空间，维数至多 $d$。当 $n>d$ 时它只是 $\mathbb{R}^n$ 里的一张“低维薄片”，而 $y$ 因噪声几乎总在薄片之外。

> **直觉 Intuition｜$n=3,\ d=2$ 的画面**
>
> 把 3 个样本想成三维空间里的一个点 $y$；$X$ 的两列张成一个过原点的平面。$y$ 通常不在这个平面上。我们要在平面上找**离 $y$ 最近的点** $\hat{y}$，再反推它是哪组系数 $\hat{\beta}$ 造出来的。

### 0.10.5 关键一步：为什么残差必然垂直于列空间

平面上“点到直线的最近点是垂足”，高维也一样：**子空间中离 $y$ 最近的点 $\hat{y}$ 必然满足 $y-\hat{y}$ 与子空间垂直。** 证明只用勾股定理。

设 $\hat{y}=X\hat{\beta}$ 是 $\operatorname{Col}(X)$ 里离 $y$ 最近的点，$u=Xc$ 是空间里任取的另一点。把 $y-u$ 拆成两段：

$$
y-u=(y-\hat{y})+(\hat{y}-u)
$$

若 $y-\hat{y}\perp\hat{y}-u$，由勾股定理

$$
\lVert y-u\rVert^2=\lVert y-\hat{y}\rVert^2+\lVert \hat{y}-u\rVert^2
$$

右边第二项 $\ge0$，所以 $\lVert y-u\rVert^2\ge\lVert y-\hat{y}\rVert^2$，等号仅在 $u=\hat{y}$ 时成立——**只有残差垂直于列空间时，$\hat{y}$ 才最短**。

“残差垂直于整个列空间”等价于“与 $X$ 的**每一列**都垂直”。把 $d$ 条“与第 $j$ 列正交”的条件摞起来：

$$
X^{\top}e=0
$$

（$X^{\top}$ 的每一行恰好是 $X$ 的一列，所以 $X^{\top}e=0$ 就是逐列点积为 0。）

### 0.10.6 从正交条件推出正规方程（每一步都解释）

把 $e=y-X\hat{\beta}$ 代进去，逐步得到正规方程：

$$
\begin{aligned}
X^{\top}e=0
&\Longleftrightarrow X^{\top}(y-X\hat{\beta})=0 &&(\text{代入残差定义})\\
&\Longleftrightarrow X^{\top}y-X^{\top}X\hat{\beta}=0 &&(\text{分配律，见 }0.9.1)\\
&\Longleftrightarrow \boxed{X^{\top}X\hat{\beta}=X^{\top}y} &&(\text{移项})
\end{aligned}
$$

最后这个方程叫 **Normal Equations 正规方程**。**它不是背下来的公式，而是“残差垂直于每一列”这条几何条件的代数翻译。** 三个因子各是什么（回顾 0.9.5）：

| 因子            | 维度          | 含义                                                  |
| --------------- | ------------- | ----------------------------------------------------- |
| $X^{\top}X$   | $d\times d$ | Gram 矩阵：对角元是各特征平方和，非对角元是特征间内积 |
| $X^{\top}y$   | $d\times1$  | 每个特征与响应$y$ 的内积（共同变化）                |
| $\hat{\beta}$ | $d\times1$  | 待求的估计系数                                        |

**什么时候能写成显式公式？** 当 $X$ 满列秩（$\operatorname{rank}(X)=d$，各列线性无关）时，$X^{\top}X$ 可逆，于是

$$
\hat{\beta}=(X^{\top}X)^{-1}X^{\top}y
$$

> **易错点 Common Pitfall｜先有正规方程，才有求逆公式**
>
> $X^{\top}X\hat{\beta}=X^{\top}y$ **总是有解**（这是投影一定存在的保证）；而 $\hat{\beta}=(X^{\top}X)^{-1}X^{\top}y$ 只在 $X^{\top}X$ 可逆时才成立。第 4 周 rank 不足 / 完全共线性时 $X^{\top}X$ 不可逆，正规方程仍成立，但不能这样求逆——那时系数不唯一。

### 0.10.7 同一答案的另一条路：微积分视角

几何给出正规方程；**微积分（优化）也给出同一条**。把 RSS 展开成二次函数（0.6–0.7 的导数与梯度）：

$$
\operatorname{RSS}(\beta)=(y-X\beta)^{\top}(y-X\beta)=y^{\top}y-2\beta^{\top}X^{\top}y+\beta^{\top}X^{\top}X\beta
$$

对 $\beta$ 求梯度 $\nabla_\beta\operatorname{RSS}$（把每个偏导数摞成向量）：

$$
\nabla_\beta\operatorname{RSS}=-2X^{\top}y+2X^{\top}X\beta
$$

令梯度为 0（极小值的一阶条件）并约掉 2：

$$
-2X^{\top}y+2X^{\top}X\beta=0\;\Longrightarrow\;X^{\top}X\beta=X^{\top}y
$$

**和几何推导得到的是同一条正规方程**。而且 RSS 是**凸**的（$X^{\top}X$ 半正定，0.7.1），所以“梯度为 0 的点”就是全局最小，不必担心只是局部最优。

> **直觉 Intuition｜两种视角，一件事**
>
> - **几何**：$y$ 不在列空间里，就在里面找最近的投影点，残差 ⊥ 列空间。
> - **微积分**：把残差平方和当函数，找让它最小的 $\beta$，令梯度为 0。
>
> 两条路殊途同归。Week 4 还会接上第三条——**概率**：若误差服从高斯分布，“最小二乘”同时就是“最大似然”（Gaussian MLE）。

### 0.10.8 两个小算例：把公式落到数字上

**算例一（只有截距）：答案就是样本均值。** 若模型只有一个截距，$X$ 只有一列全是 1。正交条件 $X^{\top}e=0$ 变成

$$
1^{\top}e=\sum_i (y_i-\hat{\beta})=0\;\Longrightarrow\;\hat{\beta}=\bar{y}
$$

即“只画一条水平线”时，最小二乘给出的高度正是样本均值。换个角度：$X^{\top}X=n$、$X^{\top}y=\sum_i y_i$，代入公式 $\hat{\beta}=(X^{\top}X)^{-1}X^{\top}y=(1/n)\sum_i y_i=\bar{y}$，一致。

**算例二（0.9 的小数据）：真的把 $X^{\top}e=0$ 算出来。** 3 个样本、$x=[1,2,3]$、$y=[2,3,5]$，含截距，$X=\begin{bmatrix}1&1\\1&2\\1&3\end{bmatrix}$。由正规方程解得 $\hat{\beta}=(1/3,\ 3/2)^{\top}$，于是

$$
\hat{y}=X\hat{\beta}=\begin{bmatrix}1.833\\3.333\\4.833\end{bmatrix},\qquad
e=y-\hat{y}=\begin{bmatrix}0.167\\-0.333\\0.167\end{bmatrix}
$$

代入正交条件：

$$
X^{\top}e=\begin{bmatrix}1&1&1\\1&2&3\end{bmatrix}\begin{bmatrix}0.167\\-0.333\\0.167\end{bmatrix}=\begin{bmatrix}0\\0\end{bmatrix}
$$

**残差与 X 的两列都正交**：第一个 0 是 $1^{\top}e=\sum_i e_i=0$（残差和为零），第二个 0 是 $x^{\top}e=\sum_i x_i e_i=0$（残差与 x 没有线性关系）。这就是 $X^{\top}e=0$ 在具体数字上的样子——它不是一个抽象口号，而是拿计算器就能验证的事实。（残差和 / 乘积出现的 0.000 来自四舍五入。）

**顺带一提（帽子矩阵）。** 把 $\hat{\beta}$ 代回预测，就得到一个"一步到位"的投影式：

$$
\hat{y}=X\hat{\beta}=X(X^{\top}X)^{-1}X^{\top}y=Hy,\qquad H=X(X^{\top}X)^{-1}X^{\top}
$$

$H$ 叫 Hat Matrix 帽子矩阵（4.10 节详述），它满足对称 $H^{\top}=H$、幂等 $H^2=H$——这两个性质正是"投影"在代数上的指纹，可用来交叉验证前面的几何推理自洽。

> **抓住主线 Key Idea｜优化的观点和几何的观点是同一件事**
>
> 从微积分出发（令梯度为 0）得到正规方程；从几何出发（作正交投影）也得到正规方程。Week 4 再把它们与概率观点（Gaussian MLE）统一起来。

## 0.11 Norm 范数、Distance 距离与 Orthogonality 正交

*为什么讲这节？* 残差平方和 RSS 就是残差向量的范数平方；“残差与特征正交”是 OLS 最优解的几何标志（第 4 章）。

Norm 范数衡量“向量有多大”。最常用的是 Euclidean Norm 欧氏范数（也叫 $L_{2}$ 范数）：

$$
\lVert v\rVert_{2}=\sqrt{\sum_{j}v_{j}^{2}}=\sqrt{v^{\top}v}
$$

它是勾股定理在多维的推广，也正好给出两点之间的 Euclidean Distance 欧氏距离： 

$$
\lVert u-v\rVert_{2}=\sqrt{\sum_{j}(u_{j}-v_{j})^{2}}
$$

小算例：$v=(3,4)$ 时 $\lVert v\rVert_2=\sqrt{3^2+4^2}=5$（正是 3-4-5 直角三角形的斜边）；$u=(1,0)$ 与 $v=(0,1)$ 满足 $u^{\top}v=0$，所以这两个方向正交。

用到回归上，$\lVert y-X\beta \rVert^{2}_{2}$ 就是所有 Residual 残差平方的总和，也就是 RSS：

$$
\lVert y - X\beta \rVert^{2}_{2} = \sum_{i} (y_{i} - x_{i}^{\top}\beta)^{2} = \operatorname{RSS}(\beta)
$$

Orthogonality 正交意味着点积为 0；在 OLS 最优解处，Residual Vector 残差向量 e 与 Design Matrix 设计矩阵的每个列方向正交：$X^{\top}e=0$。这是“在已有特征方向上，已经没有能被继续解释的剩余部分”的严格说法。

> **直觉 Intuition｜“正交”就是“已经榨干信息”**
>
> 残差 $e$ 与每个特征方向都垂直，意味着特征里能被线性解释的部分已被模型用尽：无论再沿特征方向怎么调整，都只会把预测推得离 $y$ 更远。所以“残差 ⊥ 列空间”与“这是离 y 最近的投影点”其实是同一件事的两种说法。

| 概念           | 公式                                              | 回归里的用途           |
| -------------- | ------------------------------------------------- | ---------------------- |
| $L_{2}$ 范数 | $\lVert v\rVert_{2}$                            | 向量长度、RSS          |
| 欧氏距离       | $\lVert u-v\rVert_{2}$                          | 点与点、点与空间的远近 |
| 正交           | $u^{\top}v=0$ | 残差与特征垂直，$X^{\top}e=0$ |                        |

## 0.12 Optimization 优化：arg min / arg max 到底是什么

*为什么讲这节？* “估计参数”在数学上就是解一个 $\arg\min$ 或 $\arg\max$；后面几乎每一章都在做这件事。

$\min f(\beta)$ 是“最小的函数值”，$\arg\min_{\beta} f(\beta)$
是“让函数达到最小的那个
$\beta$”。统计学习更关心后者，因为我们要找的是参数。

| 写法                                                                                                  | 问的问题                             |
| ----------------------------------------------------------------------------------------------------- | ------------------------------------ |
| $\hat{\beta} = \arg\min_{\beta} \operatorname{RSS}(\beta)$ | 哪一组$\beta$ 让残差平方和最小？     |                                      |
| $\hat{\theta}_{\mathrm{MLE}} = \arg\max_{\theta} L(\theta)$ | 哪一个$\theta$ 让已观察数据最可能？ |                                      |
| $\hat{c} = \arg\min_{c} \operatorname{CV}(c)$                                                       | 哪一个模型复杂度让交叉验证误差最小？ |

“min”和“arg min”的区别值得单独强调：min 返回一个数值（最小的函数值），arg min 返回一个位置（取得该数值的自变量）。例如 $f(x)=(x-3)^{2}$，$\min f=0$，而 $\arg\min f=3$。

优化还要区分 Global 全局与 Local 局部：局部最优只说“附近最好”，全局最优才是“整个定义域最好”。若函数是 Convex 凸的，两者合一，省去大量麻烦。此外，极值可能出现在两类地方：

1. Interior 内部点：梯度为 0 的驻点。
2. Boundary 边界点：例如 MLE 的 $\hat{p}$ 被约束在 $[0,1]$ 内，最优解可能恰好落在端点 0 或 1。

Week 2 推导 MLE 时，先解一阶条件，再检查二阶条件（或直接用凸性）确认是最大值，最后确认它落在允许范围内。

## 0.13 Probability 概率论前置

*为什么讲这节？* 概率是后面五周的共同语言：第 1 章打地基，第 2–3 章用它谈估计与不确定性，第 4–5 章用它给误差建模。

概率论是后面五周的共同语言。这里把课程真正会用到的概念按“从简单到复杂”的顺序铺开。

### 0.13.1 样本空间、事件与概率公理

- Sample Space 样本空间 $\Omega$：一次随机试验所有可能结果的集合。掷一次骰子 $\Omega=\{1,2,3,4,5,6\}$。
- Event 事件 A：样本空间的一个子集。$\{1,2,3\}$ 就是“点数不超过 3”。
- Probability 概率 $P(A)$：给每个事件分配一个 0 到 1 之间的数，满足三条公理：

$$
0\le P(A)\le 1, \qquad P(\Omega)=1, \qquad P(\varnothing)=0
$$

再加上“互斥事件概率可加”：若 $A\cap B=\varnothing$，则 $P(A\cup B)=P(A)+P(B)$。由此得到补集公式 $P(A^{c})=1-P(A)$。

### 0.13.2 条件概率与独立性

$$
P(A\mid B) = \frac{P(A\cap B)}{P(B)}, \qquad P(B)>0
$$

读法是“在已知 B 发生的世界里，A 占多大比例”。等价地有乘法法则 $P(A\cap B)=P(A\mid B)P(B)=P(B\mid A)P(A)$。

小算例：掷一枚骰子，A =“点数不超过 3”$=\{1,2,3\}$，B =“是偶数”$=\{2,4,6\}$。则 $P(A\mid B)=P(A\cap B)/P(B)=P(\{2\})/P(\{2,4,6\})=(1/6)/(3/6)=1/3$。注意分母换成了 B 的“世界”。

Independence 独立性：若 $P(A\cap B)=P(A)P(B)$，则 A、B 独立，此时 $P(A\mid B)=P(A)$——知道 B 不改变对 A 的判断。注意“互斥”和“独立”完全是两回事：互斥是“不能同时发生”，独立是“互不影响”。

### 0.13.3 全概率公式与 Bayes 公式

如果 $B_{1},\ldots ,B_{k}$ 把所有可能情况分割完（互斥且并为 $\Omega$），则

$$
P(A)=\sum_{j}P(A\mid B_{j})P(B_{j}) \quad(\text{Law of Total Probability 全概率公式})
$$

把它代进条件概率定义，就得到 Bayes’ Rule 贝叶斯公式：

$$
P(B_{j}\mid A)=\frac{P(A\mid B_{j})P(B_{j})}{\sum_{l}P(A\mid B_{l})P(B_{l})}
$$

可以把它记成“后验 $\propto$ 似然 $\times$ 先验”：分子里的 $P(A\mid B_{j})$ 是 Likelihood 似然，$P(B_{j})$ 是 Prior 先验，分母是 Evidence 证据概率。第 1 章医学检测的例子正是这个公式：先验率很低时，即使灵敏度很高，假阳性仍可能淹没真阳性。

小算例（两组情况）：某工厂甲、乙两条产线，产量占比分别为 70%、30%，次品率分别为 2%、5%。抽到一件次品 D，它来自甲线 A 的概率是 $P(A\mid D)=\dfrac{P(D\mid A)P(A)}{P(D\mid A)P(A)+P(D\mid B)P(B)}=\dfrac{0.02\times0.7}{0.02\times0.7+0.05\times0.3}\approx0.483$。先验（产量占比高）会把“来自甲线”的可信度从 2% 大幅抬到约 48%。

### 0.13.4 随机变量与分布函数

Random Variable 随机变量 X 是把每种随机结果映射成数字的函数。它把“事件”翻译成“数值”，才能做加减、求平均。

| 类型            | 描述工具                                                                                                       | 性质 |
| --------------- | -------------------------------------------------------------------------------------------------------------- | ---- |
| Discrete 离散   | PMF Probability Mass Function 概率质量函数$p_X(x)=P(X=x)$ | 每个取值是一个正概率，$\sum_{x}p_X(x)=1$       |      |
| Continuous 连续 | PDF Probability Density Function 概率密度函数$f_X(x)$ | 点是 0 概率，靠区间面积给概率，$\int f_X(x)\,dx=1$ |      |

对连续变量，概率是面积：

$$
P(a\le X\le b)=\int_{a}^{b}f_X(x)\,dx
$$

CDF Cumulative Distribution Function 累积分布函数 $F_X(x)=P(X\le x)$ 对离散和连续都适用。

> **易错点 Common Pitfall｜密度不是“点概率”**
>
> 连续变量里 $P(X=x)$ 通常为 0；真正的概率来自一段区间下的面积。PDF 密度值甚至可以大于 1，只要总面积为 1。

### 0.13.5 期望、方差与协方差

Expectation 期望是“概率加权的长期平均”：

$$
E[X]=\sum_x x\,p_X(x)\quad(\text{离散}), \qquad E[X]=\int x f_X(x)\,dx\quad(\text{连续})
$$

三个最重要的性质是线性性与常数处理：

$$
E[c]=c, \qquad E[cX]=cE[X], \qquad E[X+Y]=E[X]+E[Y]
$$

注意第三条不需要 X、Y 独立，非常强大。此外，若 X、Y 独立，还有 $E[XY]=E[X]E[Y]$。

Variance 方差描述围绕均值的波动，$\mu=E[X]$：

$$
\operatorname{Var}(X)=E[(X-\mu)^{2}]=E[X^{2}]-E[X]^{2}
$$

必须记住的变换性质是

$$
\operatorname{Var}(c)=0, \qquad \operatorname{Var}(cX)=c^{2}\operatorname{Var}(X), \qquad \operatorname{Var}(X+c)=\operatorname{Var}(X)
$$

——常数不改变波动，但系数要平方。Standard Deviation 标准差是 $\sigma=\sqrt{\operatorname{Var}(X)}$：方差的单位是原变量的**平方**（例如身高以米计时，方差的单位是“平方米”），开平方后的标准差才和原变量同单位，所以两者不能直接比大小。

小算例：$X$ 等概率取 0 或 1，则 $E[X]=0.5$，$E[X^{2}]=0.5$，$\operatorname{Var}(X)=0.5-0.5^2=0.25$，标准差 $\sigma=0.5$；再如掷一枚均匀骰子，$E[X]=(1+2+\cdots+6)/6=3.5$。

下面这条“和”的方差公式会在第 3 章反复出现：

$$
\operatorname{Var}(X+Y)=\operatorname{Var}(X)+\operatorname{Var}(Y)+2\operatorname{Cov}(X,Y)
$$

若 X、Y 独立（更一般地不相关），$\operatorname{Cov}(X,Y)=0$，方差可以直接相加。

Covariance 协方差衡量两个量是否一起动：

$$
\operatorname{Cov}(X,Y)=E[(X-E[X])(Y-E[Y])]=E[XY]-E[X]E[Y]
$$

为正表示“X 高时 Y 也偏高”，为负表示“一高一低”，接近 0 表示没有明显的线性共同变化。Correlation 相关系数 $\rho=\operatorname{Cov}(X,Y)/(\sigma_X\sigma_Y)$ 是它的标准化版本，取值恒在 $[-1,1]$

> **易错点 Common Pitfall｜Zero covariance 零协方差 ≠ Independence 独立**
>
> 独立一定零协方差，但零协方差不一定独立。Tutorial 1 的挑战题：$X\in\{-1,0,1\}$ 等概率，$Y=X^{2}$。$\operatorname{Cov}(X,Y)=0$，但 Y 完全由 X 决定，绝不独立。协方差只能看到线性共同变化。

### 0.13.6 四个必须认识的概率模型

| Distribution 分布  | 参数               | 均值 / 方差               | 适合描述                      |
| ------------------ | ------------------ | ------------------------- | ----------------------------- |
| Bernoulli 伯努利   | $p$              | $p$ / $p(1-p)$        | 一次 0/1 结果                 |
| Binomial 二项      | $n,p$            | $np$ / $np(1-p)$      | n 次独立 Bernoulli 中成功次数 |
| Poisson 泊松       | $\lambda$        | $\lambda$ / $\lambda$ | 固定时间/空间内的事件计数     |
| Gaussian 高斯/正态 | $\mu,\sigma^{2}$ | $\mu$ / $\sigma^{2}$  | 围绕中心连续波动的数值        |

Bernoulli 的期望推导非常典型：取值只有 0、1，$E[X]=0\cdot(1-p)+1\cdot p=p$。Gaussian 的 PDF 长这样：

$$
f(x)=\frac{1}{\sqrt{2\pi\sigma^{2}}}\exp\!\left(-\frac{(x-\mu)^{2}}{2\sigma^{2}}\right)
$$

指数里的 $-(x-\mu)^{2}/(2\sigma^{2})$ 让“离中心越远、密度越小”；前面的常数只是把总面积调成 1。

### 0.13.7 i.i.d. 与可加性

若 $X_{1},\ldots ,X_{n}$ 是 Independent and Identically Distributed 独立同分布（i.i.d.），则

- 每个样本同分布：$E[X_{i}]=\mu$、$\operatorname{Var}(X_{i})=\sigma^{2}$ 都相同；
- 彼此独立：联合分布可拆成乘积 $p(x_{1},\ldots ,x_{n})=\prod_{i}p(x_{i})$，方差公式里的 2 倍协方差项全部消失。

这两条合起来，就能推出第 3 章的核心结果

$$
\operatorname{Var}(\bar{x})=\frac{\sigma^{2}}{n}, \qquad \operatorname{se}(\bar{x})=\frac{\sigma}{\sqrt{n}}
$$

——样本均值的波动随 n 增大而缩小，但只按 $1/\sqrt{n}$ 的速度缩小。

小算例：若单个样本的标准差 $\sigma=10$，取 $n=100$，则 $\operatorname{se}(\bar{x})=10/\sqrt{100}=1$；样本量加到 400（4 倍），标准误才减半到 0.5——精度提升比直觉的慢得多。

### 0.13.8 大数定律与中心极限定理

- Law of Large Numbers 大数定律：n 越大，样本均值 $\bar{x}$ 越接近总体均值 $\mu$。这是“用样本估计总体”的合法性来源。
- Central Limit Theorem 中心极限定理：在 i.i.d.、且总体**方差有限**（因而均值也有限）的前提下，当 n 足够大时，**样本均值（或样本和）的标准化分布**近似标准正态：

$$
\frac{\bar{x}-\mu}{\sigma/\sqrt{n}}\xrightarrow{d}\mathcal{N}(0,1)
$$

它解释了为什么高斯分布无处不在，也是置信区间、t 检验的理论基础。

三点提醒：(1) 它讲的是**“样本均值这个统计量”的分布**近似正态，不是原始数据变成正态——原始数据该偏还是偏；(2) “n 足够大”没有统一门槛，总体越对称所需 n 越小；(3) 它成立需要独立同分布与方差有限，否则结论可能失效。

小算例：掷一枚骰子（原始分布是均匀的、并不正态），单次均值 3.5、方差约 2.92；连掷 $n=30$ 次再取平均，平均值的分布已很接近钟形，中心仍是 3.5，标准误约 $\sqrt{2.92/30}\approx0.31$。这也顺带体现大数定律：掷得越多，平均值越稳稳落在 3.5 附近。

### 0.13.9 条件期望与条件方差

回归真正建模的是 Conditional Expectation 条件期望 $E[Y\mid X=x]$，可以理解为“给定 x 后 Y 的平均值”。两条会用到的性质是

$$
E[Y]=E\big[E[Y\mid X]\big] \quad(\text{全期望公式}), \qquad
\operatorname{Var}(Y)=E\big[\operatorname{Var}(Y\mid X)\big]+\operatorname{Var}\big(E[Y\mid X]\big) \quad(\text{全方差公式})
$$

第一条说明“无条件平均 = 各条件平均再平均”；第二条说明总波动可以拆成“组内波动”与“组间波动”，是理解回归拟合优度和方差分解的钥匙。

## 0.14 最关键的统计思维：Parameter 参数固定，Data 数据随机

*为什么讲这节？* 这是理解偏差、方差、标准误、Bootstrap（第 3 章）与系数不确定性（第 4 章）的总开关。

很多初学者最难跨过去的一步，不是微积分，而是“重复抽样”视角。Parameter
参数 $\theta$ 描述总体，通常被视为固定但未知；Sample
样本是随机抽来的，所以由样本算出的 Estimator 估计量 $\hat{\theta}$
也会随样本改变。后面 Bias 偏差、Variance 方差、Standard Error
标准误、Bootstrap 自助法，全部建立在这个视角上。

小算例：抛 10 次均匀硬币、数正面个数。真相是“正面概率 $\theta=0.5$”这个**固定**参数；但每一次拿到的样本不同，算出的比例 $\hat{\theta}$（这次 6/10、下次 4/10、再下次 5/10……）一直在动。**参数不动、估计值在动**——这就是“参数固定、数据随机”的全部含义，也是后面偏差、方差、标准误的出发点。

> **抓住主线 Key Idea｜一句话**
>
> 总体参数像“真正的答案”，我们看不见；样本像“抽到的一张线索卡”；估计量是“根据线索猜答案的规则”。不同线索卡会让猜测不同。

## 0.15 一眼拆开本课程最吓人的公式

*为什么讲这节？* 这是第 4 周线性回归的最终目标公式；先在这里用“逐项翻译 + 几何直觉 + 小算例”拆一次，正式推导时就不会被它吓到。

$$
\hat{\beta} = (X^{\top}X)^{-1}X^{\top}y
$$

1. $X^{\top}X$（$d\times d$ 的格拉姆矩阵）：把特征之间的重叠与尺度信息汇总起来——对角元是各特征自身的平方和，非对角元是特征之间的内积。
2. $(X^{\top}X)^{-1}$：在列满秩（各特征线性无关）时，把这种特征几何关系“解开”，作用类似数字里“除以一个数”。
3. $X^{\top}y$（$d\times 1$）：汇总每个特征与响应 y 的共同变化。
4. 最终 $\hat{\beta}$（$d\times 1$）：得到一组最小化 Residual Sum of Squares
   残差平方和的系数。

小算例（只有截距）：若 X 只有一列全是 1，则 $X^{\top}X=n$、$X^{\top}y=\sum_i y_i$，于是 $\hat{\beta}=(1/n)\sum_i y_i=\bar{y}$。连“最吓人的公式”在只拟合一条水平线时，也退化成“求平均数”——说明它并不神秘。

真正做数值计算时，软件通常不会显式求 $(X^{\top}X)^{-1}$，而会用 QR
Decomposition QR 分解或 SVD Singular Value Decomposition
奇异值分解；课件保留这个公式主要是为了推导和理解。

CLT 说的是大样本下**样本均值的标准化分布**近似标准正态（需 i.i.d. 且方差有限），据此可构造置信区间；12. 残差向量 e 与设计矩阵的列空间正交，即 $X^{\top}e=0$；13. 变成 $c^{\,n}\prod_i a_i$（$n$ 为项数，这点与 $\sum$ 不同）；且 $\prod_i(a_i+b_i)\ne\prod_i a_i+\prod_i b_i$；14. 方差单位是“平方米”，标准差单位才是“米”，所以标准差与原变量同单位、可直接比较；15. 预测的是**条件均值** $E[Y\mid X=x]$（给定 x 时 y 平均是多少），因为同样的 x 对应的 y 会随机波动，回归不假装知道某个确定的未来值；16. $\beta$ 是固定但未知的真实系数，$\hat{\beta}$ 是用数据算出的估计（帽子 = 估计）；$y$ 是真实观测，$\hat{y}=X\hat{\beta}$ 是模型预测；$\varepsilon$ 是相对真实均值的误差（算不出），$e=y-\hat{y}$ 是相对拟合均值的残差（能算出）；17. $X$ 是 $3\times2$（首列全 1、第二列 $1,2,3$），$y$ 是 $3\times1$；带帽子表示它是**由数据估计出来的**系数，而不是未知真相 $\beta$。

## 1.3 Probability 概率与 Probability Distribution 概率分布

Sample Space 样本空间 $\Omega$ 是所有可能结果的集合；Event 事件 A
是其中一部分结果。Probability 概率 $P(A)$ 介于 0 和 1 之间。Probability
Distribution 概率分布则说明“不确定性如何分配到所有可能值上”。

$$
0 \le P(A) \le 1, P(\Omega)=1
$$

## 1.4 Random Variable 随机变量：把随机结果变成数字

Random Variable 随机变量 X
是一个把每种随机结果映射成数字的函数。比如“一小时进店人数”在事前不知道，所以是随机变量；观察结束后得到具体数字
$x=17$。大写 X 强调“还没看到结果”，小写 x 强调“已经看到”。

## 1.5 PMF 概率质量函数与 PDF 概率密度函数

|      | Discrete 离散                                                  | Continuous 连续      |
| ---- | -------------------------------------------------------------- | -------------------- |
| 对象 | 可数的取值                                                     | 连续区间上的取值     |
| 函数 | PMF 概率质量函数$p_X(x)=P(X=x)$ | PDF 概率密度函数$f_X(x)$ |                      |
| 总量 | $\sum_x p_X(x)=1$                                            | $\int f_X(x)dx=1$  |
| 例子 | 成功次数、报警数量                                             | 温度、身高、测量误差 |

> **易错点 Common Pitfall｜密度不是“点概率”**
>
> 对具有 PDF 的连续变量，任意单点的 $P(X=x)=0$；真正的概率来自区间下的面积：$P(a\le X\le b)=\int_a^b f_X(x)\,dx$。密度值可以大于 1，只要总面积为 1。
>
> 例如在 $[0,0.5]$ 上均匀分布时，区间内密度为 2，但 $P(0\le X\le0.1)=2\times0.1=0.2$，并不是 2。密度是“每单位长度分配多少概率”，不是概率本身。

## 1.7 Conditional Probability 条件概率：换一个“分母世界”

$$
P(A\mid B) = P(A\cap B) / P(B), P(B)>0
$$

Conditional Probability 条件概率不是把 A
的概率“修改一下”，而是先把世界缩小到 B
已经发生的那些情况，再问其中有多少也属于 A。最实用的直觉是：条件符号 $|$
左边是“想问的”，右边是“已知的”。

这里 $A\cap B$ 表示“A、B 同时发生”。例如 20 人中有 8 人戴眼镜，其中 3 人也戴帽子，则 $P(\text{戴帽子}\mid\text{戴眼镜})=3/8$，分母是已知戴眼镜的 8 人，而非全部 20 人。

## 1.8 Bayes’ Rule 贝叶斯公式：从“原因→证据”反推“证据→原因”

课件的医学检测例子非常重要。Disease 疾病先验率只有 2%；Sensitivity
灵敏度 $P(+\mid D)=90\%$；False Positive Rate 假阳性率
$P(+\mid D^{c})=8\%$。我们真正想知道的是 Positive Predictive Probability
阳性后患病概率 $P(D\mid +)$。

$$
P(D\mid +) = P(+\mid D)P(D) / [P(+\mid D)P(D)+P(+\mid D^{c})P(D^{c})]
$$

$$
= 0.90\times 0.02 / [0.90\times 0.02 + 0.08\times 0.98] \approx 0.187
$$

所以“检测灵敏度 90%”绝不等于“阳性后 90% 患病”。在 10,000 人中，大约 200
人患病，其中 180 人阳性；9,800 人不患病，其中约 784 人假阳性。全部阳性
964 人里，真正患病只有 180 人，即 18.7%。

| Term 术语              | 问题                     | 本例                  |
| ---------------------- | ------------------------ | --------------------- |
| Prior 先验             | 看证据前相信多少？       | $P(D)=2\%$          |
| Likelihood term 似然项 | 某状态下看到证据的概率？ | $P(+\mid D)=90\%$   |
| Posterior 后验         | 看到证据后更新到多少？   | $P(D\mid +)=18.7\%$ |
| Evidence 证据概率      | 这个证据总体多常见？     | $P(+)$              |

## 1.9 Precision 精确率、Recall / Sensitivity 召回率/灵敏度、Specificity 特异度

| Measure 指标                       | 分母是谁？       | 本例                      |
| ---------------------------------- | ---------------- | ------------------------- |
| Recall / Sensitivity 召回率/灵敏度 | 所有真正患病的人 | 180/200=90%               |
| Precision 精确率                   | 所有被判阳性的人 | $180/964\approx 18.7\%$ |
| Specificity 特异度                 | 所有真正没病的人 | 9016/9800=92%             |

> **抓住主线 Key Idea｜三者别混**
>
> Recall 问“真阳性抓住多少”；Precision
> 问“判阳性里有多少是真的”；Specificity
> 问“真阴性排除多少”。它们的分母不同。

## 1.10 Expectation 期望：概率加权的长期平均

$$
E[X]=\sum_x x\,p_X(x)\quad(\text{离散}),\qquad E[X]=\int x f_X(x)\,dx\quad(\text{连续})
$$

公平六面骰子的 Expected Value 期望是 3.5，但你永远掷不出
3.5。它不是“一次会出现的典型值”，而是重复很多次后的长期平均中心。

## 1.11 Population 总体量与 Sample Statistic 样本统计量

| Population / Model 总体或模型                                                                                          | Observed Sample 观测样本 |
| ---------------------------------------------------------------------------------------------------------------------- | ------------------------ |
| Mean 均值$\mu=E[X]$ | Sample Mean 样本均值$\bar{x}=(1/n)\sum_{i}x_{i}$                                             |                          |
| Variance 方差$\sigma^{2}=\operatorname{Var}(X)$ | Sample Variance 样本方差$s^{2}=(1/(n-1))\sum(x_{i}-\bar{x})^{2}$ |                          |
| 固定但通常未知                                                                                                         | 换一个样本就会变         |

> **易错点 Common Pitfall｜为什么有时除 n，有时除 n−1？**
>
> 课件在描述某一组已列出的数据“有多分散”时用 denominator n 的 Empirical
> Variance 经验方差；把 $s^{2}$ 当作总体方差 $\sigma^{2}$ 的 Unbiased
> Estimator 无偏估计量时使用 n−1。后面 Week 2 会再次看到 MLE 方差用 n。

## 1.12 Variance 方差：平均离中心多远，但先平方

$$
\operatorname{Var}(X) = E[(X-\mu)^{2}] = E[X^{2}] - E[X]^{2}
$$

式中 $\mu=E[X]$ 是总体均值，$E[X^2]$ 是“先平方再平均”，$E[X]^2$ 是“先平均再平方”，两者不要混。以等概率取 1、3 为例，$\mu=2$，方差 $=(1+9)/2-2^2=1$，标准差为 1。

平方有两个作用：第一，正负偏差不会互相抵消；第二，大偏差被更重地惩罚。Variance
方差的单位是原单位的平方，所以实际解释时也常看 Standard Deviation 标准差
$\sigma=\sqrt{\operatorname{Var}(X)}$。

## 1.13 Covariance 协方差：两个量是否一起动

$$
\operatorname{Cov}(X,Y) = E[(X-E[X])(Y-E[Y])]
$$

Covariance 协方差为正，表示 X 高于自己平均值时 Y
往往也高；为负则常一高一低；接近 0 只表示没有明显的线性共同变化。

> **易错点 Common Pitfall｜Zero covariance 零协方差 ≠ Independence
> 独立**
>
> Tutorial 1 的挑战题：$X\in\{-1,0,1\}$ 等概率，$Y=X^{2}$。由于 $E[X]=0$、$E[XY]=E[X^3]=0$，协方差为 0；但 $P(Y=0)=1/3$，而 $P(Y=0\mid X=0)=1$，所以不独立。协方差只能看到线性共同变化；独立要求知道 X 后，Y 的分布仍不变。

## 1.14 Gaussian Distribution 高斯分布与 Multivariate Gaussian 多元高斯

$$
X \sim \mathcal{N}(\mu,\sigma^{2})
$$

Gaussian Distribution 高斯分布是一条钟形曲线。Mean 均值 $\mu$
决定中心位置，Variance 方差 $\sigma^{2}$ 决定宽窄。多维数据用 Random
Vector 随机向量 X 表示，并写作 $X\sim \mathcal{N}(\mu,\Sigma)$：Mean
Vector 均值向量 $\mu$ 决定中心，Covariance Matrix 协方差矩阵 $\Sigma$
决定各方向的伸展与倾斜。

### 题 1：离散概率模型

给定 $X\in\{0,1,2,3\}$，$P(X=x)=c(x+1)$。概率总和必须为
1：c(1+2+3+4)=10c=1，所以 $c=0.1$。

$$
E[X]=0\times 0.1+1\times 0.2+2\times 0.3+3\times 0.4=2
$$

$$
E[X^{2}]=0+1^{2}\times 0.2+2^{2}\times 0.3+3^{2}\times 0.4=5 \Rightarrow \operatorname{Var}(X)=5-2^{2}=1
$$

$$
P(X\ge 2\mid X\ge 1)=(0.3+0.4)/(0.2+0.3+0.4)=7/9
$$

若改成长时间窗口里的“告警次数”，Poisson Distribution
泊松分布通常最自然，典型假设是事件以近似恒定速率、相互独立地发生。

### 题 2：供应商、缺陷与检测

先对齐符号与已知量：A、B 是供应商，供货比例为 70%、30%，缺陷率分别为 1%、5%；D 表示有缺陷，F 表示被检测标记。检测对缺陷品的标记率为 90%，对无缺陷品的误标率为 4%，且给定是否缺陷后，标记概率不再依赖供应商。

$$
P(D)=0.70\times 0.01+0.30\times 0.05=0.022
$$

$$
P(F)=0.90\times 0.022+0.04\times 0.978=0.05892
$$

$$
P(D\mid F)=0.90\times 0.022 / 0.05892 \approx 0.336
$$

$$
P(B\mid F)=0.30\times [0.90\times 0.05+0.04\times 0.95] / 0.05892 \approx 0.423
$$

Flagged 被标记不仅让“缺陷”的后验概率上升，也让“来自供应商
B”的后验概率上升，因为 B 的缺陷率更高。Bayes
的本质就是：证据会同时更新所有与证据有关的隐藏原因。

### 题 3：组合两个有噪声的传感器

X、Y 都是无偏测量：$E[X]=E[Y]=\theta$，$\theta$ 是待测真值。已知 $\operatorname{Var}(X)=4$、$\operatorname{Var}(Y)=9$、$\operatorname{Cov}(X,Y)=3$。定义 $Z_w = wX+(1-w)Y$，其中 w 是分给 X 的权重。

组合方差遵循 $\operatorname{Var}(aX+bY)=a^2\operatorname{Var}(X)+b^2\operatorname{Var}(Y)+2ab\operatorname{Cov}(X,Y)$，所以本题交叉项系数为 $2\times3=6$。

$$
E[Z_w]=w\theta+(1-w)\theta=\theta\quad\Rightarrow\quad Z_w\ \text{仍然无偏}
$$

$$
\operatorname{Var}(Z_w)=4w^{2}+9(1-w)^{2}+6w(1-w)=7w^{2}-12w+9
$$

$$
d/dw \operatorname{Var}(Z_w)=14w-12=0 \Rightarrow w=6/7
$$

$$
\min \operatorname{Var}(Z_w)=27/7\approx 3.857 < \operatorname{Var}(X)=4 < \operatorname{Var}(Y)=9
$$

若保持两者方差不变而令 $\operatorname{Cov}(X,Y)=0$，最优组合方差会更小，因为少了同向波动的交叉项；这里应说噪声“不相关”，不能仅据此说“独立”。当误差强烈同向变化时，平均不能消掉太多共同噪声。

## 2.1 Parameter 参数、Estimator 估计量、Estimate 估计值

## 2.2 i.i.d. 独立同分布为什么如此常见

Independent
独立意味着一个样本结果不改变另一个样本结果的概率；Identically
Distributed 同分布意味着每个样本遵循同一个参数化模型。i.i.d.
假设让联合概率可以拆成乘积，也让平均数等统计量有干净的性质。

$p(x_{1},\ldots ,x_{n}\mid \theta) = \prod_{i} p(x_{i}\mid \theta)$（在给定模型参数后独立时）

$\theta$ 是未知参数的统称，$i$ 是观测编号，$\prod$ 表示把各项相乘；离散模型中的 p 是概率质量，连续模型中对应概率密度。独立允许拆乘积，同分布让每一项使用同一个分布。比如同一人连续测三次血压往往相关，不能自动当作三个独立的人。

## 2.3 Method of Moments 矩估计：让“模型的平均特征”对上“样本的平均特征”

矩是 $E[X^{k}]$ 这样的总体量，k 表示幂次。矩估计的想法非常朴素：模型说总体应该有什么平均特征；样本给出对应的经验平均；把两者设成相等，解出未知参数。下面的等号是**用来定义估计值的匹配方程**：左侧代入待求参数，右侧代入实际数据；不是声称每个样本的平均都恰好等于真实总体矩。

$$
E[X^{k}] = (1/n)\sum_{i} X_{i}^{k}
$$

> **直觉 Intuition｜为什么叫“矩”？**
>
> 不要被名字吓到。第一矩就是 $E[X]$；第二原点矩是
> $E[X^{2}]$。如果模型有两个未知参数，通常需要两条独立的矩方程。

## 2.4 Bernoulli 伯努利模型的 MoM

若 $X\sim \mathrm{Bernoulli}(p)$，则 $E[X]=p$。样本第一矩就是
$\bar{x}$，所以直接得到 $\hat{p}_{\mathrm{MM}}=\bar{x}$。对 0/1
数据而言，样本均值恰好就是成功比例。

$$
\hat{p}_{\mathrm{MM}} = \bar{x}
$$

## 2.5 Gaussian 高斯模型的 MoM

Gaussian 模型 $X\sim \mathcal{N}(\mu,\sigma^{2})$
有两个未知参数，所以需要两个矩。第一矩 $E[X]=\mu$；由
$\operatorname{Var}(X)=E[X^{2}]-E[X]^{2}$ 得
$E[X^{2}]=\mu^{2}+\sigma^{2}$。

$$
\hat{\mu}_{\mathrm{MM}} = \bar{x}
$$

$$
\hat{\sigma}^{2}_{\mathrm{MM}} = (1/n)\sum_{i} X_{i}^{2} - \bar{x}^{2} = (1/n)\sum_{i}(X_{i}-\bar{x})^{2}
$$

注意这里自然出现分母 n。矩估计追求的是“矩匹配”，不是专门追求无偏性。

## 2.6 Likelihood 似然：固定数据，移动参数

概率模型与似然使用同一个表达式，但固定的对象不同：固定 $\theta$、让数据 x 变化时，它描述数据的概率质量或密度；固定已看到的数据 x、让 $\theta$ 变化时，$L(\theta)=p(x\mid\theta)$ 就是似然。连续数据应写成密度 $f(x\mid\theta)$，而不是单点概率 $P(X=x\mid\theta)$。

例如独立观察到 H、H、T，$L(p)=p^2(1-p)$。候选 $p=0.5$ 的似然是 0.125，$p=2/3$ 的似然是 $4/27\approx0.148$，所以后者更兼容这组数据。这不表示“p 等于 2/3 的概率是 14.8%”；似然也不要求对参数求和或积分为 1。

|      | Probability 概率 | Likelihood 似然            |
| ---- | ---------------- | -------------------------- |
| 固定 | 参数$\theta$   | 观测数据 x                 |
| 变化 | 可能数据 x       | 候选参数$\theta$         |
| 问题 | 会看到什么？     | 哪个参数更兼容已观察数据？ |

> **易错点 Common Pitfall｜Likelihood 不是参数为真的概率**
>
> 频率学派 Maximum Likelihood 最大似然里，$L(\theta)$ 不是
> $P(\theta\mid data)$。若要讨论参数的后验概率分布，需要 Bayes 公式与
> Prior 先验。

## 2.7 Maximum Likelihood Estimation 最大似然估计

$$
\hat{\theta}_{\mathrm{MLE}} = \arg\max_{\theta} L(\theta) = \arg\max_{\theta} \ell(\theta)
$$

$\arg\max$ 表示“找出使后面表达式最大的参数”，不是返回最大似然值本身。对数似然 $\ell(\theta)=\operatorname{log} L(\theta)$ 通常使用自然对数。由于 log 单调递增，最大值位置不变；同时 $\prod$（连乘）变成 $\sum$（求和），所以推导更简单。

## 2.8 Bernoulli MLE：为什么又得到样本比例

设 n 次独立 Bernoulli 中观察到 m 次成功。Likelihood 为
$L(p)=p^{m}(1-p)^{n-m}$；对数似然
$\ell(p)=m \operatorname{log} p+(n-m)\operatorname{log}(1-p)$。

$$
\ell'(p)=m/p - (n-m)/(1-p)
$$

$$
\ell'(p)=0 \Rightarrow \hat{p}_{\mathrm{MLE}}=m/n=\bar{x}
$$

当 $0<m<n$ 时，二阶导数在 $0<p<1$ 内为负，所以这个驻点是最大值。若全失败（m=0）或全成功（m=n），最大值在边界 p=0 或 p=1，仍得到 $\hat p=m/n$，但不能套用内部驻点求导。这次矩估计与最大似然恰好相同，一般模型中不一定如此。

## 2.9 Likelihood 的“峰有多尖”也有信息

在相同模型、可比较的独立样本下，两个数据集可以有同一个 MLE，但样本量较大的似然通常在最大点附近下降得更快。比较曲线宽窄时可看相对似然 $L(\theta)/L(\hat\theta)$（把各自峰高归一到 1），不要直接比较不同样本量下原始似然的高度。峰的位置告诉你“最支持哪个参数”；峰附近下降的快慢提示局部估计稳定性。这是第 3 章不确定性的入口，不是说似然本身就是参数的概率分布。

## 2.10 Gaussian MLE：均值与方差

$$
\ell(\mu,\sigma^{2})=C - (n/2)\operatorname{log}\sigma^{2} - [1/(2\sigma^{2})]\sum_{i}(x_{i}-\mu)^{2}
$$

这里 C 是与 $\mu,\sigma^2$ 无关的常数，可在寻找最大点时忽略；n 是样本量，平方偏差之和衡量数据离候选中心有多远。均值偏离数据中心或方差大小不合适，都会降低对数似然。

先对 $\mu$ 求偏导并令 0，得到
$\hat{\mu}_{\mathrm{MLE}}=\bar{x}$。再代回并对 $\sigma^{2}$ 优化，得到：

$$
\hat{\sigma}^{2}_{\mathrm{MLE}} = (1/n)\sum_{i}(x_{i}-\bar{x})^{2}
$$

> **抓住主线 Key Idea｜为什么不是 n−1？**
>
> 因为 MLE 的目标是“让似然最大”，这个优化问题直接给出 denominator n。n−1
> 的 Sample Variance 样本方差是为了得到对 $\sigma^{2}$ 的 Unbiased
> Estimator 无偏估计量。目标不同，公式就不同。

## 2.11 Bias 偏差、Variance 方差、Consistency 一致性

| Property 性质                   | 定义/直觉                                                                                                                        |
| ------------------------------- | -------------------------------------------------------------------------------------------------------------------------------- |
| Bias 偏差                       | $\operatorname{\mathrm{Bias}}(\hat{\theta})=E[\hat{\theta}]-\theta$；是否系统性偏高或偏低                                      |
| Variance 方差                   | $\operatorname{Var}(\hat{\theta})=E[(\hat{\theta}-E\hat{\theta})^{2}]$；换样本后估计变化多大                                   |
| Consistency 一致性              | 对任意$\varepsilon>0$，$P(\lvert\hat\theta_n-\theta\rvert>\varepsilon)\to0$；大误差的概率随 n 增大而趋零，并非每次增样都更准 |
| MSE Mean Squared Error 均方误差 | $E[(\hat{\theta}-\theta)^{2}]=\operatorname{\mathrm{Bias}}^{2}+\mathrm{Variance}$                                              |

> **直觉 Intuition｜Unbiased 无偏不等于“每次都准”**
>
> 无偏只说“重复很多次后的平均估计等于真值”。一个无偏估计量仍然可能方差巨大；反过来，轻微有偏但非常稳定的估计量，MSE
> 反而可能更小。

## 3.1 同一个 Point Estimate 点估计，可以有完全不同的可信度

10 次抛硬币有 6 次正面，与 100 次有 60 次正面，都会给
$\hat{p}=0.6$。但后者更稳定。对 Bernoulli
比例，$\operatorname{Var}(\hat{p})=p(1-p)/n$，所以样本量 n
越大，抽样波动越小。

> **抓住主线 Key Idea｜Point estimate tells where; uncertainty tells how
> reliable**
>
> 点估计告诉你“中心在哪里”；不确定性告诉你“这个中心有多稳”。Week 3
> 的所有工具都在回答第二个问题。

## 3.2 Sampling Distribution 抽样分布

Estimator 估计量 $\hat{\theta}=T(X_{1},\ldots ,X_{n})$
在观察数据之前本身是 Random Variable
随机变量。想象从同一总体重复做很多次研究，每次都重新抽 n 个样本并计算
$\hat{\theta}$，就会得到
$\hat{\theta}^{(1)},\hat{\theta}^{(2)},\ldots$。这些估计值形成的概率分布就是
Sampling Distribution 抽样分布。

Sampling Distribution = “同一总体 + 同一 n + 重复抽样”下 $\hat{\theta}$
的分布

不要混淆三种分布：**总体分布**描述随机抽一个人的身高；**样本的经验分布**描述眼前这批人的身高；**抽样分布**描述每次重新抽 n 人算出的平均身高。第三种的一个“点”是整批人的统计量，不是一个人的观测值。

## 3.3 Standard Error 标准误不是 Standard Deviation 标准差

$$
\operatorname{se}(\hat{\theta}) = \sqrt{\operatorname{Var}(\hat{\theta})}
$$

|            | Standard Deviation 标准差 | Standard Error 标准误    |
| ---------- | ------------------------- | ------------------------ |
| 谁在变？   | 原始观测 X                | 估计量$\hat{\theta}$   |
| 描述什么？ | 个体数据有多分散          | 重复研究的估计有多分散   |
| 例子       | 人的身高差异              | 样本均值换样本后变化多大 |

严格说，SE 本身就是“估计量抽样分布的标准差”。本节对照的 SD 特指**原始观测值**的标准差，不能把“SE 与 SD 不同”误读为两种完全无关的数学量。

例如身高总体 SD 为 10 cm，独立抽 100 人时，均值的 SE 为 $10/\sqrt{100}=1$ cm。抽更多人不会让个体身高差异消失，却能让平均身高估得更稳。

## 3.4 为什么样本均值越来越稳定

若 $X_{i}$
独立，$E[X_{i}]=\mu$，$\operatorname{Var}(X_{i})=\sigma^{2}$，则
$\bar{x}=(1/n)\sum X_{i}$。独立性让方差可以相加：

$$
\operatorname{Var}(\bar{x})=\sigma^{2}/n \Rightarrow \operatorname{se}(\bar{x})=\sigma/\sqrt{n}
$$

> **直觉 Intuition｜$1/\sqrt{n}$ 的代价**
>
> 样本量翻倍，SE 不会减半；要把 SE 减半，通常要把独立样本量扩大约 4
> 倍。这就是“更多数据收益递减”的数学来源。

## 3.5 Central Limit Theorem 中心极限定理

若 $X_1,\ldots,X_n$ 独立同分布且每个都服从高斯分布，样本均值对任意 n 都精确服从 $\mathcal{N}(\mu,\sigma^{2}/n)$。不要求总体为高斯时，本章使用的经典中心极限定理条件是：样本独立同分布，且总体均值有限、方差满足 $0<\sigma^2<\infty$。此时随 n 增大，标准化后的样本均值趋近标准正态分布：

$$
\frac{\bar{x}-\mu}{\sigma/\sqrt{n}}\xrightarrow{d}\mathcal{N}(0,1)
$$

分子 $\bar{x}-\mu$ 是估计误差，分母 $\sigma/\sqrt n$ 是均值的标准误；相除就是把误差换成“几个标准误”的尺度。$\xrightarrow{d}$ 表示依分布收敛，讨论的是重复抽样下的分布形状，不是说某个样本均值必然等于真值。

强偏态或重尾会使近似收敛较慢，没有“n≥30 就一律可靠”的保证；若总体方差无限，这个经典版本不适用。有相关性的数据也不能直接套本式。CLT 让**均值的抽样分布**近似正态，不会把原始数据变成正态。

## 3.6 Plug-in Principle 代入原则

理论公式里常有未知总体量。例如
$\operatorname{se}(\bar{x})=\sigma/\sqrt{n}$，但 $\sigma$
不知道。最自然的做法是用样本估计 s
代进去：$\widehat{\operatorname{se}}(\bar{x})=s/\sqrt{n}$。Bootstrap
自助法把这个想法推到极致：不仅替换一个参数，而是用 Empirical
Distribution 经验分布 $\hat{F}_{n}$ 替换整个未知总体分布 F。

## 3.7 Empirical Distribution 经验分布与 Bootstrap 自助法

经验分布 $\hat{F}_{n}$ 把概率 1/n 放在每一条观测记录上；若同一个值出现多次，其概率相加。自助法暂时把它当作总体，再“有放回地”抽 n 条记录，得到自助样本 $D^*$，用原来的估计规则算出一个自助复制值 $\hat{\theta}^{*}$。星号表示“来自重抽数据”，不是新参数。

这里介绍的是适用于独立同分布观测的普通非参数自助法；一条观测若包含身高、体重等多个特征，应整行重抽，不能把各列分别打乱。

1. 从原始数据 D 算 $\hat{\theta}$。
2. 从 D 中有放回抽 n 次，得到 D\*。
3. 在 D\* 上算同一个统计量 $\hat{\theta}*$。
4. 重复 B 次，得到
   $\hat{\theta}^{*(1)},\ldots ,\hat{\theta}^{*(B)}$。
5. 用这些复制值的中心、标准差和分位数近似真实抽样分布的特征。

## 3.8 为什么必须 With Replacement 有放回抽样

如果原样本有 n 个值，你“无放回”再抽 n
个，只会得到同一批值的不同排列；均值、中位数等统计量完全不变，没有任何重抽样波动。有放回后，有些点会重复、有些点会缺席，才会产生可用的变化。

$$
P(\text{某个观测一次都没被抽到})=(1-1/n)^n\approx e^{-1}\approx0.368
$$

所以不同原始记录的期望占比为 $1-(1-1/n)^n$，n 较大时约为 63.2%。这是平均比例，不是每次重抽的固定比例；不同记录即使数值相同，也按不同记录计数。

## 3.9 Bootstrap 到底在近似什么

$$
\text{真实世界: }F\to D\to\hat{\theta}\qquad \text{Bootstrap 世界: }\hat F_n\to D^*\to\hat{\theta}^*
$$

$$
\hat{\theta}^{*} - \hat{\theta} \approx \hat{\theta} - \theta
$$

我们无法看到 $\hat{\theta}$ 围绕真参数 $\theta$
的真实重复抽样波动，于是用 $\hat{\theta}*$ 围绕当前估计 $\hat{\theta}$
的波动来模拟它。上式的 $\approx$ 指**分布形状的近似**，不是两边在某次重抽中数值相等；它需要样本能代表总体、估计量适合这种近似等条件。自助分布不是“真正的抽样分布”，而是以当前数据为条件的近似，也不是参数的后验分布。

## 3.10 Bootstrap Standard Error 自助标准误与 Bootstrap Bias 自助偏差

$$
\bar{\theta}^*=\frac{1}{B}\sum_b \hat{\theta}^{*(b)}
$$

$$
\operatorname{se}_{\mathrm{boot}}=\sqrt{\frac{1}{B-1}\sum_b\left(\hat{\theta}^{*(b)}-\bar{\theta}^*\right)^2}
$$

$$
\operatorname{Bias}_{\mathrm{boot}}=\bar{\theta}^*-\hat{\theta}
$$

这里 b 是重抽编号，B 是重抽次数，$\bar\theta^*$ 是 B 个复制值的平均，不是原数据均值。B−1 用于计算这些复制值的样本标准差。

注意：$\operatorname{se}_{\mathrm{boot}}$ **不再除以 $\sqrt B$**，因为它要估计原估计量的波动，而不是 B 个复制值平均数的波动。增大 B 会让模拟更精确，但不等于增加真实观测量 n。自助偏差也只是偏差的估计，接近 0 不能证明真实偏差为 0。

## 3.11 Percentile Bootstrap Interval 百分位自助区间

把 B 个 $\hat{\theta}^*$ 排序，直接取 2.5% 与 97.5% 分位数，得到**名义置信水平为 95%** 的百分位自助区间。分位数就是排序后的相应位置；例如自助均值的两个分位数为 18.2、21.6，则区间为 [18.2,21.6]。不同软件对有限 B 的位置插值可能略有差异。

它不强制区间左右对称，但“能呈现偏斜”不等于“自动校正偏差”。样本太小、估计量偏差明显或接近参数边界时，实际覆盖率可能远离 95%；不能把取中间 95% 的复制值等同于已经证明 95% 的覆盖率。

$$
CI_{0.95}^{\mathrm{perc}}=\left[\hat{\theta}^{*}_{0.025},\hat{\theta}^{*}_{0.975}\right]
$$

> **易错点 Common Pitfall｜95% Confidence 的正确理解**
>
> Parameter 参数 $\theta$
> 在频率学派里是固定的；随机的是“如果重做研究，会得到哪个区间”。一个 95%
> Confidence Procedure 置信程序意味着长期重复研究时，大约 95%
> 的区间会覆盖同一个真参数。这里的“重复”包括重新采集原始样本并重新构造区间，不是在同一数据上仅反复重抽。
>
> 已经算出的某一个区间要么包含真参数、要么不包含；不能解释成“真参数有 95% 概率落在这个固定区间内”，也不是“95% 的个体观测落在里面”。自助区间只是尝试近似这样的程序，是否接近名义覆盖率仍取决于数据与方法条件。

## 3.12 Bootstrap 什么时候会失败

| Failure Case 失败情形                        | 为什么                                                            |
| -------------------------------------------- | ----------------------------------------------------------------- |
| Unrepresentative Data 样本不代表总体         | 重抽再多次也只是在重复偏掉的样本                                  |
| Dependence 依赖结构被忽略                    | 不能把同一病人的多次测量当成独立病人                              |
| Rare Events 稀有事件未出现                   | 经验分布里没有的事件，非参数 Bootstrap 造不出来                   |
| Extreme / Boundary Estimator 极值/边界估计量 | 样本最大值等统计量可能无法由原样本重抽正确模拟尾部                |
| B 太小                                       | 只是 Monte Carlo Simulation Noise 模拟噪声大；增大 B 可改善这一点 |

> **抓住主线 Key Idea｜B 很大也不是万能药**
>
> 增大 B
> 只能减少“第二层”的模拟误差，不能修复原始样本偏差、错误的独立单位或不稳定统计量。

## 3.13 Paired Bootstrap 配对自助法

两个分类器在同一批测试样本上比较时，每条记录形成一对 $(C_{Ai},C_{Bi})$，其中 C=1 表示预测正确，C=0 表示错误。重抽“样本索引”，让 A、B 同时跟着同一个索引走，再计算准确率差 $\hat\Delta^*=\overline C_A^*-\overline C_B^*$，才能保留二者在同一测试例上的相关性。

例如抽到索引 [2,2,5]，两模型都必须使用第 2、2、5 条结果，不能 A 抽一组、B 另抽一组。这里默认不同测试记录相互独立；若同一病人有多条记录，应按病人等独立单位分组重抽。固定已训练模型、只重抽测试记录，衡量的是测试样本带来的波动，不含重新训练模型的波动。

## 4.1 Regression 回归真正学的不是某个 y，而是 Conditional Mean 条件均值

$$
m(x)=E[Y\mid X=x]
$$

$$
Y = m(X) + \varepsilon, E[\varepsilon\mid X]=0
$$

同样的广告投入不一定每周产生完全相同销量，所以回归不假装未来 y
是确定的。它先学习“在给定 x 时平均会是多少”，再把个体偏离平均的部分放进
Error / Noise 误差/噪声 ε。

例如，广告费同为 100 元的三周，销量分别为 18、20、22 件，样本平均为 20 件；它是在估计 $m(100)$，不是断言下一周一定卖 20 件。$E[Y\mid X=x]$ 的“条件”就是先固定广告投入再谈平均，而不是把所有广告投入下的销量混在一起平均。$\varepsilon=Y-m(X)$ 是相对真实均值的偏离，通常不可直接观察；后面的残差则是相对**拟合均值**的偏离。

## 4.2 Simple Linear Regression 简单线性回归

$$
E[Y\mid X=x] = \beta_{0} + \beta_{1}x
$$

Intercept 截距 $\beta_{0}$ 是 $x=0$ 时的条件均值；Slope 斜率 $\beta_{1}$
是 x 每增加 1 单位时，条件均值改变多少。多元回归只是把一个 x 换成很多
Features 特征。

$$
E[Y\mid X=x] = \beta_{0} + \beta_{1}x_{1} + \cdots + \beta_{p}x_{p} = x^{\top}\beta
$$

这里有 $p$ 个特征；写成内积时，$x=[1,x_1,\ldots,x_p]^\top$ 包含截距对应的 1，$\beta=[\beta_0,\ldots,\beta_p]^\top$。这是假设真实条件均值可用该线性式表示；若不成立，OLS 只能找这个模型族内的最佳拟合，不能保证学到真实均值。$x=0$ 若远离观测范围，截距主要用于定位直线，不宜赋予实际含义。

## 4.3 “Linear 线性”到底线性在哪里

Linear Regression 线性回归要求对未知系数 $\beta$
是线性的，不要求对原始输入 x 必须是直线。例如
$\beta_{0}+\beta_{1}x+\beta_{2}x^{2}$ 对 x 是曲线，但对
$\beta_{0},\beta_{1},\beta_{2}$ 仍然只是线性加权，因此仍可用 OLS。Week 5
的 Polynomial Regression 多项式回归就靠这一点。

判断时看“未知量怎样出现”：$\beta_2x^2$ 是未知权重乘已知特征，仍对参数线性；$e^{\beta_1x}$ 的未知参数藏在指数里，就不是这里的线性参数模型。“能画成曲线”与“对参数非线性”是两回事。

## 4.4 Design Matrix 设计矩阵与 Matrix Form 矩阵形式

$$
y = X\beta + \varepsilon
$$

把每个样本的特征行堆起来形成 X，把响应堆成 y，就能把 n
条方程压成一条。Population Model 总体模型用未知 $\beta$；Fitted Model
拟合模型用估计 $\hat{\beta}$。

本章记 $n$ 为样本数、$d=p+1$ 为含截距的系数个数：$X$ 是 $n\times d$ 矩阵，每行一个样本、每列一个特征，第一列全为 1；$y,\varepsilon$ 是 $n\times1$ 向量，$\beta$ 是 $d\times1$ 向量。注意矩阵 $X$ 在这里指整批数据，不是 4.1 中单个随机输入。$x_i^\top$ 是 $X$ 的第 $i$ 行。

$$
\hat{y} = X\hat{\beta}, e = y-\hat{y}
$$

## 4.5 Residual 残差为什么要平方

Residual 残差
$e_{i}=y_{i}-\hat{y}_{i}$。直接把残差相加会发生正负抵消：残差 +4 和 −4
总和为 0，却显然不是好拟合。这里的 +4、−4 是可计算的残差示例，不是已经知道真实 $\varepsilon_i$。于是 OLS 用 Residual Sum of Squares
残差平方和 RSS。残差 $e_i=y_i-\hat y_i$ 可由数据算出；误差 $\varepsilon_i=y_i-m(x_i)$ 依赖未知真实均值，通常算不出。二者不能互换。

贯穿案例中，拟合线为 $\hat y=1/3+(3/2)x$（4.18 展示推导）。在 $x=2$ 时，预测 $10/3$、实测 $3$，所以残差为 $-1/3$：模型把这一点高估了。但真实均值未知，不能据此说真实误差也为 $-1/3$。

$$
\operatorname{RSS}(\beta)=\sum_{i}(y_{i}-x_{i}^{\top}\beta)^{2} = \lVert y-X\beta \rVert^{2}_{2}
$$

$$
\hat{\beta} = \arg\min_{\beta} \operatorname{RSS}(\beta)
$$

## 4.6 简单线性回归的 Closed Form 封闭解

$$
\hat{\beta}_{1} = \sum_{i}(x_{i}-\bar{x})(y_{i}-\bar{y}) / \sum_{i}(x_{i}-\bar{x})^{2}
$$

$$
\hat{\beta}_{0} = \bar{y} - \hat{\beta}_{1}\bar{x}
$$

分子像“x 与 y 的共同变化”，分母像“x 自己有多少变化”。如果 x
几乎不变，就很难估计斜率；若所有 $x_i$ 相同，分母为 0，斜率无法唯一估计。

贯穿案例中，$\bar x=2$、$\bar y=10/3$，分子为 $(-1)(-4/3)+0\cdot(-1/3)+1\cdot(5/3)=3$，分母为 $(-1)^2+0^2+1^2=2$。所以斜率为 $3/2$、截距为 $10/3-(3/2)\cdot2=1/3$。这与矩阵法是同一个解，不是两套不同的回归。

## 4.7 Multiple Regression 多元回归与 Normal Equations 正规方程

把 RSS 展开并对 $\beta$ 求 Gradient 梯度：

$$
\nabla_{\beta} \operatorname{RSS} = -2X^{\top}y + 2X^{\top}X\beta
$$

$$
X^{\top}X\hat{\beta} = X^{\top}y
$$

$$
\hat{\beta}=(X^\top X)^{-1}X^\top y
$$

把这条矩阵公式翻译成步骤：先算 $X^\top y$，汇总每个特征与响应的乘积；再用 $X^\top X$ 中的特征交叉乘积解出各权重。维度依次为 $X^\top X:d\times d$、$X^\top y:d\times1$，最终得到 $\hat\beta:d\times1$，所以不是直接把两个矩阵“相除”。

正规方程来自“令梯度等于 0”；这个逆矩阵公式仅在 $X$ 满列秩（$\operatorname{rank}(X)=d$）时成立。它要求有足够样本且列之间没有完全重复的信息。实际软件通常用 QR 或 SVD 解最小二乘，不必显式求逆；4.18 题 1 则用小矩阵展示计算过程。

> **易错点 Common Pitfall｜什么时候不唯一？**
>
> 若 $\operatorname{rank}(X)<d$，说明特征列线性依赖。例如
> $x_{2}=2x_{1}$，模型只能识别 $\beta_{1}+2\beta_{2}$
> 这个组合，无法唯一拆分两个系数。

## 4.8 为什么 Gaussian MLE 与 OLS 是同一件事

给定设计矩阵 $X$，若误差相互独立且 $\varepsilon_{i}\mid X\sim \mathcal{N}(0,\sigma^{2})$（共同方差 $\sigma^2$），则
$Y_{i}\mid x_{i}\sim \mathcal{N}(x_{i}^{\top}\beta,\sigma^{2})$。Gaussian
Log-Likelihood 中与 $\beta$ 有关的部分恰好是
$-(1/2\sigma^{2})\sum(y_{i}-x_{i}^{\top}\beta)^{2}$，所以最大化似然等价于最小化
RSS。

$$
\text{Gaussian MLE for }\beta=\text{OLS}
$$

> **抓住主线 Key Idea｜OLS 本身不要求 Gaussian**
>
> “最小平方”作为优化准则可以不假设高斯；Gaussian
> 假设让它获得概率解释，并支持经典的 t 分布、置信区间等推断。

## 4.9 Geometry 几何视角：OLS 是 Projection 投影

X 的列张成一个 Column Space 列空间，模型能产生的所有预测 ŷ
都在这个空间里。OLS 选择离 y 最近的那个 ŷ，也就是把 y 正交投影到
Col(X)。

$$
\hat y=\operatorname{Proj}_{\operatorname{Col}(X)}(y),\qquad e=y-\hat y,\qquad X^\top e=0
$$

$X^{\top}e=0$
意味着残差已经与每个特征方向正交：在线性意义上，没有剩余的“沿着已有特征还能继续解释”的方向。

## 4.10 Hat Matrix 帽子矩阵与 Leverage 杠杆值

$$
H = X(X^{\top}X)^{-1}X^{\top}, \hat{y}=Hy
$$

Hat Matrix 帽子矩阵把 y “戴上帽子”变成 ŷ。对角元素 $h_{ii}$ 是 Leverage
杠杆值，描述第 i 个样本的 Feature Position 特征位置有多不寻常。Leverage
只由 X 决定，不看 y。此处逆矩阵仍要求满列秩；$H$ 为 $n\times n$，$h_{ii}$ 表示第 $i$ 个观测的 $y_i$ 对自身拟合值的权重。含截距的一元回归中，离 $\bar x$ 越远通常杠杆越高，但这不等于它一定影响很大。一个能心算的例子：$h_{ii}=\frac{1}{n}+\frac{(x_i-\bar x)^2}{\sum_j(x_j-\bar x)^2}$。取 4.18 题 1 的 $x=1,2,3$（$\bar x=2$，分母为 $2$），三个杠杆分别为 $5/6,\ 1/3,\ 5/6$，相加恰好等于系数个数 $2$；这也解释了 $0\le h_{ii}\le1$ 且 $\sum_i h_{ii}=d$。

## 4.11 Coefficient Interpretation 系数解释与 Uncertainty 不确定性

在多元回归中，$\beta_{j}$ 表示“其他特征保持不变时，$x_{j}$ 增加 1
单位，Conditional Mean
条件均值改变多少”。这个解释适用于没有相关交互项或非线性变换的加性模型；而且系数数值会随单位缩放而改变。

例如“控制门店面积后，广告费每增加 100 元，平均销量高 3 件”，描述的是模型中的条件关联，不自动意味着**主动多投 100 元就会多卖 3 件**。旺季可能同时提高广告投入和销量，造成混杂；因果解释还需要随机实验或有依据的因果识别假设。若模型同时含 $x$ 与 $x^2$，改变 $x$ 会改变两列，变化率是 $\beta_1+2\beta_2x$，不能只读 $\beta_1$。

$$
\hat{\beta} = \beta + (X^{\top}X)^{-1}X^{\top}\varepsilon
$$

这条分解直接说明：Coefficient Estimate
系数估计的不确定性来自数据噪声经过矩阵变换后的结果。若
$E[\varepsilon\mid X]=0$，则 $E[\hat{\beta}\mid X]=\beta$，即 OLS
在该假设下 Unbiased 无偏。

## 4.12 OLS 系数方差与 Standard Error 标准误

以下经典公式假定均值模型正确、$X$ 满列秩，且给定 $X$ 时误差均值为 0、方差都为 $\sigma^2$、相互不相关，即 $\operatorname{Var}(\varepsilon\mid X)=\sigma^2I$。方差公式本身不要求正态；后面的精确 t 推断才需要高斯假设。

$$
\operatorname{Var}(\hat{\beta}\mid X) = \sigma^{2}(X^{\top}X)^{-1}
$$

不确定性由三件事控制：Noise Level 噪声 $\sigma^{2}$ 越大越不稳；Feature
Information 特征变化越充分越稳；Feature Correlation
特征高度相关时，单个系数更难分离。

$$
\hat{\sigma}^{2} = \operatorname{RSS}/(n-d)
$$

$$
\operatorname{SE}(\hat{\beta}_{j})=\hat{\sigma}\sqrt{(X^{\top}X)^{-1}_{jj}}
$$

这里 $n-d$ 是残差自由度，估计 $\sigma^2$ 要求 $n>d$；$\hat\sigma$ 是其平方根，$(\cdot)_{jj}$ 取矩阵中与该系数对应的对角项。SE 描述“换一批同样方式抽样的数据，系数估计会波动多大”，不是单个销量的波动，也不是系数本身的大小。

## 4.13 Confidence Interval 置信区间与 Prediction Interval 预测区间

对系数 $\beta_{j}$，在 Gaussian Regression 高斯回归下使用 t Distribution
t 分布：

$$
\hat{\beta}_{j} \pm t_{1-\alpha/2,\,n-d} \cdot \operatorname{SE}(\hat{\beta}_{j})
$$

对新输入 $x_{0}$，有两个不同问题：Mean Response 平均响应
$E[Y\mid x_{0}]$ 与 Future Observation 单个未来观测
$Y_{0}$。后者还多一份新的不可约噪声 $\varepsilon_{0}$，所以 Prediction
Interval 预测区间在相同置信水平、相同输入和同一模型下通常更宽（噪声方差为正时严格更宽）。

$$
\operatorname{SE}(\text{mean at }x_0)=\hat\sigma\sqrt{x_0^\top(X^\top X)^{-1}x_0}
$$

$$
\operatorname{SE}(\text{prediction})=\hat\sigma\sqrt{1+x_0^\top(X^\top X)^{-1}x_0}
$$

贯穿案例里，$n=3,d=2,RSS=1/6$，所以 $\hat\sigma^2=(1/6)/(3-2)=1/6$。新输入为原始 $x=2$ 时，含截距向量 $x_0=[1,2]^\top$，计算得 $x_0^\top(X^\top X)^{-1}x_0=1/3$。均值的 SE 为 $\sqrt{(1/6)(1/3)}\approx0.236$，单次预测的 SE 为 $\sqrt{(1/6)(1+1/3)}\approx0.471$。多出的“1”正是新观测噪声的贡献。此例只剩 1 个残差自由度，95% 的 t 分位数约为 12.706，实际区间仍会很宽；不能把小 SE 直接当成窄区间，更不能凭三点验证模型假设。

两种区间都以 $\hat y_0=x_0^\top\hat\beta$ 为中心，分别加减 $t_{1-\alpha/2,n-d}$ 乘以上述 SE。$x_0$ 是含截距 1 的新特征列向量；$\alpha=0.05$ 对应 95% 水平，$t$ 是自由度 $n-d$ 的 t 分位数。这些精确区间沿用 4.8 的独立同方差高斯误差假设，未来误差还须独立于训练数据并服从同一噪声模型。此外，两个区间的宽度都由 $x_0^\top(X^\top X)^{-1}x_0$ 决定，它随 $x_0$ 远离训练中心 $\bar x$ 而增大，所以在 $\bar x$ 附近最窄、越往外越宽——这正是远离数据处（外推）预测更不可靠的直接体现。

**把两个问题分开：**同样广告费下，“很多周的平均销量”可能估为 20 件、均值置信区间为 [19,21]；“下一周实际销量”的预测区间可能是 [14,26]（仅作示意）。前者只担心均值估得不准，后者还要担心下一周自身的随机波动。95% 置信是指重复抽样并按此方法构造区间，约 95% 的区间覆盖真实参数，不是说已固定的真实参数有 95% 概率落入这一次区间。若 $x_0$ 远离训练范围，形式上能算区间，也不能保证外推时模型仍正确。

## 4.14 Residual Diagnostics 残差诊断

| Residual pattern 残差图形 | 可能问题                                |
| ------------------------- | --------------------------------------- |
| 随机散点、无明显结构      | 线性均值结构较合理                      |
| 弯曲趋势                  | 遗漏 Nonlinearity 非线性                |
| 漏斗/扇形                 | Heteroskedasticity 异方差               |
| 极端点                    | Outlier 异常响应或潜在 Influence 影响点 |

Heteroskedasticity 异方差主要让经典 Standard Error 标准误失真；OLS
系数本身仍按同一最小平方准则得到。实践中可用 Robust Standard Errors
稳健标准误。在条件均值模型正确且 $E[\varepsilon\mid X]=0$ 时，异方差本身不破坏 OLS 无偏性；但稳健标准误不能修复遗漏变量、错误均值结构或因果混杂。若数据按时间排列，还应检查残差是否连续同号或有周期，这提示误差相关，不能直接套独立误差公式。

## 4.15 Leverage 杠杆、Residual 残差与 Influence 影响

Residual 大说明 y 与当前拟合不一致；Leverage 大说明 x
位置不寻常。真正可能强烈改变拟合的点，往往同时具备“高杠杆 +
大残差”。Cook’s Distance 库克距离把两者合起来。

$$
D_{i} \propto e_{i}^{2} \cdot h_{ii} / (1-h_{ii})^{2}
$$

在满列秩 OLS 中，常用完整式为 $D_i=\frac{e_i^2}{d\hat\sigma^2}\frac{h_{ii}}{(1-h_{ii})^2}$（要求 $\hat\sigma^2>0$、$h_{ii}<1$）。它衡量删除第 $i$ 个点后整批拟合值的变化；高杠杆点可能已把曲线拉向自己，从而掩盖残差，不能只凭残差小就排除影响。

> **注意 Note｜Influential 不等于 Incorrect**
>
> 影响点值得调查，但不代表它是错误数据。它可能是一个真实而重要的边缘案例。

## 4.16 Multicollinearity 多重共线性与 VIF 方差膨胀因子

当多个特征携带高度重叠的信息时，模型可能仍然预测得不错，但单个系数会很不稳定。Variance
Inflation Factor 方差膨胀因子用“其他特征能把 $x_{j}$
解释到什么程度”来衡量。

$$
VIF_{j} = 1/(1-R_{j}^{2})
$$

$R_{j}^{2}$ 越接近 1，说明 $x_{j}$ 越能被其他特征重构，VIF
越大，单个系数的方差越容易膨胀。这里 $R_j^2$ 来自一个辅助回归：把 $x_j$ 当响应，用其余特征和截距预测它；不是原模型预测 $y$ 的 $R^2$。完全共线时 $R_j^2=1$，系数不再唯一。注意常见的“VIF>5”或“VIF>10”只是经验规则，并非统计定律里的硬阈值：应看它是否明显高于其他特征、以及系数在数据轻微扰动下是否剧烈摇摆。还要把两件事分开：共线性主要损害**单个系数**的解释与稳定性，不必然损害**整体预测**；反之，系数不稳定也不等于该特征与 $y$ 无关。

## 4.17 R²、Adjusted R² 与 Test MSE

$$
R^{2} = 1 - \operatorname{RSS}/TSS
$$

$R^{2}$ 比较模型与“永远预测 $\bar{y}$”的 Mean Baseline
均值基线。训练集上加特征不会让 RSS 变大，因此 $R^{2}$
只会升不降；$Adjusted R^{2}$ 调整 $R^{2}$
会惩罚复杂度，但机器学习最终仍更关心 Unseen Data 未见数据上的 Test MSE
测试均方误差。

这里 $TSS=\sum_i(y_i-\bar y)^2$；上述训练 $R^2$ 的比较针对同一数据、含截距的嵌套 OLS 模型，且 $TSS>0$。常用 $Adjusted\ R^2=1-\frac{RSS/(n-d)}{TSS/(n-1)}$（$n>d$），增加无用特征时它可能下降。$Test\ MSE=\frac1{n_{test}}\sum_i(y_i-\hat y_i)^2$ 则在未参与训练和选择的数据上计算；训练 $R^2$ 高不保证它低。比较 $Adjusted\ R^2$ 必须在**同一批数据、同一个 $y$** 上进行（例如 $y$ 取对数后不能与原 $y$ 直接比大小）；它按复杂度折减，理论上可为负，也不宜解读成“解释了百分之几”。用 4.18 题 1 心算：$RSS=1/6$，而 $TSS=(2-\tfrac{10}{3})^2+(3-\tfrac{10}{3})^2+(5-\tfrac{10}{3})^2=\tfrac{14}{3}$，于是 $R^2=1-\frac{1/6}{14/3}=1-\tfrac{1}{28}=\tfrac{27}{28}\approx0.964$，$Adjusted\ R^2=1-\frac{(1/6)/(3-2)}{(14/3)/(3-1)}=1-\tfrac{1}{14}=\tfrac{13}{14}\approx0.929$；只多一个截距以外的特征，惩罚就已经可见。

### 题 1：Matrix OLS

$X=\begin{bmatrix}1&1\\1&2\\1&3\end{bmatrix}$，$y=[2,3,5]^{\top}$。可以把三行理解为广告投入 $x=1,2,3$ 时销量为 $2,3,5$；第一列的 1 用来估计截距。按以下顺序算，不必一口气记住整个公式：

1. **汇总数据：**$X^\top X=\begin{bmatrix}3&6\\6&14\end{bmatrix}$，$X^\top y=[10,23]^\top$。其中 $3$ 是样本数，$6=1+2+3$，$14=1^2+2^2+3^2$，$23=1\cdot2+2\cdot3+3\cdot5$。
2. **求逆并乘回去：**行列式为 $3\cdot14-6^2=6\ne0$，所以 $(X^\top X)^{-1}=\frac16\begin{bmatrix}14&-6\\-6&3\end{bmatrix}$；乘以 $[10,23]^\top$ 得 $\hat\beta=[(140-138)/6,(-60+69)/6]^\top=[1/3,3/2]^\top$。
3. **逐行预测：**$\hat y_i=1/3+(3/2)x_i$，于是 $\hat{y}=[11/6,10/3,29/6]^{\top}\approx[1.833,3.333,4.833]^{\top}$。
4. **检查残差：**$e=y-\hat y=[1/6,-1/3,1/6]^\top$。第一列与残差的内积为 $1/6-1/3+1/6=0$，第二列为 $1\cdot1/6+2\cdot(-1/3)+3\cdot1/6=0$，因此 $X^\top e=0$；$RSS=1/36+1/9+1/36=1/6$。

最后一项是检查结果，不是额外强加的条件；它来自最小二乘正规方程。

$$
(X^\top X)^{-1}=\begin{bmatrix}7/3&-1\\-1&1/2\end{bmatrix}

$$

Slope 斜率系数的方差为 2，所以 Standard Error 标准误为
$\sqrt{2}\approx 1.414$。若 $\sigma^{2}$
增大，整个协方差矩阵按比例增大，标准误按 $\sigma$ 的比例增大。非对角项 $-4$ 是截距与斜率估计的协方差，不是负的方差；方差在对角线上。

不要混用两道计算：4.13 的贯穿算例用残差估计得到 $\hat\sigma^2=1/6$，本题则假定总体方差已知为 4。若本题进一步采用高斯误差且要构造区间，应使用已知 $\sigma$ 和标准正态分位数 $z$，而不是未知方差情形的 t 分位数。

# 第 5 章｜Week 5: Nonlinear Regression & Splines 非线性回归与样条

模型可以弯，但不能只追求“越弯越好”

>

> 变换特征让线性方法拟合曲线；Flexibility 灵活度带来 Bias–Variance

**本章只关心什么（从一个生活问题入手）：**空调耗电可能在温度太低或太高时都上升，一条直线难以表达这种弯曲关系。先读 5.1–5.3，学习用 $x^2$ 让曲线弯起来；再用 5.14 题 1 理解“弯得更准”为什么仍可能预测更差。接着读 5.7–5.12：分段但接得平滑就是样条，基函数只是表示它的积木。最后读 5.13 和题 3，用未见过的数据选择弯曲程度，而不是只看训练曲线好不好看。

## 5.1 从直线到 Nonlinear Mean Function 非线性均值函数

Week 4 的直线 $E[Y\mid X=x]=\beta_{0}+\beta_{1}x$
斜率恒定，无法表达“先下降后上升”或“不同区域变化速度不同”。更一般地，回归目标仍是
Conditional Mean 条件均值，只是把表示族从直线扩大为 $f(x)$。

$$
E[Y\mid X=x]=f(x), Y=f(X)+\varepsilon, E[\varepsilon\mid X]=0
$$

## 5.2 Polynomial Regression 多项式回归

$$
f_d(x)=\beta_{0}+\beta_{1}x+\beta_{2}x^{2}+\cdots +\beta_dx^{d}
$$

Degree 次数 d 越高，候选曲线越灵活。关键点是：它对 x
可以非线性，但对系数 $\beta$ 仍然是线性的，所以仍可用 OLS。

$$
\phi(x)=[1,x,x^{2},\ldots ,x^{d}]^{\top}, f(x)=\phi(x)^{\top}\beta
$$

Feature Map 特征映射 $\phi(x)$ 只是从原始 x
构造新特征，不是又测了新的变量。对所有样本做同样变换，就得到 Polynomial
Design Matrix 多项式设计矩阵 Φ。

例如选二次模型，$x=2$ 被映成 $\phi(2)=[1,2,4]^\top$；若 $\beta=[1,-2,1]^\top$，预测就是 $1-2\cdot2+1\cdot4=1$。对 $x=1,2,3$，设计矩阵为 $\Phi=\begin{bmatrix}1&1&1\\1&2&4\\1&3&9\end{bmatrix}$，然后像第 4 章一样拟合系数。**本章 $d$ 表示多项式次数，不是第 4 章的系数个数；次数 $d$ 对应 $d+1$ 个系数。**$\Phi$ 的维度是 $n\times(d+1)$，$\beta$ 为 $(d+1)\times1$，拟合值 $\hat y=\Phi\hat\beta$ 为 $n\times1$。普通 OLS 的唯一系数解仍要求设计矩阵满列秩。

**接着第 4 章的三点算：**对 $(1,2),(2,3),(3,5)$，二次曲线 $\hat f(x)=2-\tfrac12x+\tfrac12x^2$ 恰好给出 $2,3,5$，训练 RSS 为 0，比直线的 $1/6$ 更低。但在 $x=4$ 时，直线预测 $19/3\approx6.333$，二次曲线预测 8。两者分歧很大，却没有该处的新观测或真实均值可供判断，不能断言谁预测更准。三点估三个系数还使残差自由度为 0，不能把 RSS 为 0 当作“噪声为零”的证据。

## 5.3 Degree 次数为什么不能只看 Training Error 训练误差

多项式模型空间是 Nested
嵌套的：$F_{1}\subset F_{2}\subset\ldots$。高次模型可以把低次模型的最高阶系数设为
0，从而至少复现低次模型。因此训练 RSS 随 d
增大只能下降或不变。若你只看训练误差，永远会被更复杂模型“诱惑”。

> **抓住主线 Key Idea｜Training fit ≠ Prediction ability**
>
> 训练误差回答“我把已经见过的数据记得多好”；Test Error
> 测试误差回答“我对新数据预测多好”。机器学习真正关心后者。

## 5.4 Underfitting 欠拟合与 Overfitting 过拟合

|                       | Underfitting 欠拟合 | Overfitting 过拟合 |
| --------------------- | ------------------- | ------------------ |
| Flexibility 灵活度    | 太低                | 太高               |
| Training Error        | 常较高              | 常很低             |
| Squared Bias 平方偏差 | 常较高              | 常较低             |
| Variance 方差         | 常较低              | 常较高             |
| New-data Error        | 可能高              | 也可能高           |

## 5.5 Bias–Variance Decomposition 偏差-方差分解

固定一个输入 $x_{0}$。未来响应 $Y_{0}=f(x_{0})+\varepsilon_{0}$；训练集
D 不同，会得到不同的 fitted prediction 拟合预测
$\hat{f}_D(x_{0})$。把未来噪声与训练样本随机性都平均掉，可得：

$$
E\!\left[(Y_0-\hat f_D(x_0))^2\right]=\sigma^2+\operatorname{Bias}\!\left[\hat f_D(x_0)\right]^2+\operatorname{Var}_D\!\left[\hat f_D(x_0)\right]
$$

| Component 成分           | 直觉                                       |
| ------------------------ | ------------------------------------------ |
| Noise 噪声$\sigma^{2}$ | 即使知道真函数，也无法预测掉的未来随机波动 |
| Squared Bias 平方偏差    | 平均拟合函数与真函数之间的系统差距         |
| Variance 方差            | 换一份训练集，模型预测会改变多少           |

这里 $\operatorname{Bias}[\hat f_D(x_0)]=E_D[\hat f_D(x_0)]-f(x_0)$，$E_D$ 与 $\operatorname{Var}_D$ 都表示对“反复抽取训练集并重新拟合”取平均或算方差，不是对一次训练集里的不同 $x$ 取平均。该分解采用平方损失，要求相关二阶矩有限；未来噪声均值为 0、独立于训练数据，且在 $x_0$ 的方差为 $\sigma^2$。若异方差，噪声项应写成 $\sigma^2(x_0)$。

例如真实平均销量是 20：换多批训练数据，预测总在 16 附近，是偏差大；预测在 12、28 等值之间大幅摆动，即使平均接近 20，也可能方差大。这里的“方差”指预测对训练集的敏感程度，不是未来销量本身的噪声。也别与第 4 章的“OLS 系数无偏”混淆：只有均值模型等假设成立时才有该结论；用直线逼近真实曲线，预测仍可能有系统偏差。题 1 把偏差与方差变成具体数字。

模型更灵活时，Bias 往往下降，但对训练样本更敏感，Variance
往往上升。最佳复杂度不是“最简单”也不是“最复杂”，而是新数据误差最低的平衡点。

## 5.6 为什么高次 Global Polynomial 全局多项式会麻烦

Global Polynomial
全局多项式用一条公式覆盖整个输入范围。提高次数会同时影响整条曲线，边界处尤其可能剧烈摆动；$x,x^{2},x^{3},\ldots$
也可能高度相关并造成 Numerical Conditioning 数值条件差。于是课件转向
Piecewise Polynomial 分段多项式。

## 5.7 Knot 结点与 Piecewise Polynomial 分段多项式

Knot 结点 $\xi$
是相邻多项式片段相接的位置。一个结点把输入分成左右两个区域；K 个
Interior Knots 内部结点把输入分成 K+1
段。问题是：如果两段完全独立，结点处可能跳跃、折角或曲率突变。

## 5.8 Cubic Spline 三次样条的三个平滑条件

Cubic Spline 三次样条要求每段是三次多项式，并在每个内部 Knot
结点满足：函数值连续、一阶导数连续、二阶导数连续。

$$
f(\xi^-)=f(\xi^+),\qquad f'(\xi^-)=f'(\xi^+),\qquad f''(\xi^-)=f''(\xi^+)
$$

它允许 Third Derivative
三阶导数在结点处变化，因此左右两边可以拥有不同的三次形状，同时视觉上仍平滑。这里要把两个概念分清：**Piecewise Polynomial 分段多项式**只要求每段是多项式，接缝处可以跳断或出现折角；**Spline 样条**是在分段多项式之上再强制结点处若干阶导数连续（本课为函数、一阶、二阶），所以样条是“接得平滑”的分段多项式，是分段多项式的一个子集。

## 5.9 Positive-Part Function 正部函数与 Truncated Cubic 截断三次项

$$
(u)_{+} = \max(u,0)
$$

$$
(x-\xi)_+^3=\begin{cases}0,&x\le\xi\\(x-\xi)^3,&x>\xi\end{cases}
$$

这像一个“过了结点才打开的开关”。在 $\xi$
左边完全不起作用；右边逐渐贡献三次项。更妙的是，在 $x=\xi$
处它自己、一阶导数、二阶导数都等于
0，所以把它加到全局三次多项式上，不会破坏 f、$f'$、$f''$ 的连续性。

## 5.10 Truncated-Power Basis 截断幂基

$$
f(x)=\beta_0+\beta_1x+\beta_2x^2+\beta_3x^3+\sum_k\gamma_k(x-\xi_k)_+^3
$$

有 K 个内部结点时，一共有 K+4 个 Basis Functions
基函数。另一种计数方法也能得到同样答案：K+1 段三次多项式原本需要 4(K+1)
个系数；每个结点施加 3 个连续约束，所以自由度为 4(K+1)−3K=K+4。这里假定内部结点互不相同，且没有额外的边界约束或平滑惩罚。

例如仅有结点 $\xi=1$，截断项在 $x=0.5,1,1.5$ 处分别为 $0,0,1/8$。若其权重 $\gamma=2$，对预测的额外贡献就是 $0,0,1/4$；改变权重能调节结点右侧的形状，却不会在结点处突然跳跃。结点是数轴上的**位置**，$(x-1)_+^3$ 才是随 $x$ 变化的**函数**，二者不是同一件东西。

## 5.11 Basis Function 基函数是什么

Basis
基可以理解为“积木形状”。模型不是直接记一条复杂曲线，而是先准备若干固定形状
$\phi_{1}(x),\ldots ,\phi_M(x)$，再学习它们各自的权重
$\theta_{1},\ldots ,\theta_M$。

$$
f(x)=\sum_j\theta_j\phi_j(x)
$$

Polynomial Basis 多项式基用 $1,x,x^{2},\ldots$；Truncated-Power Basis
用全局三次项加结点开关；B-Spline Basis B
样条基则换成局部支撑的平滑积木。

记住三个层次：**结点**决定在哪些位置允许片段改变；**基函数**是选定结点和边界约定后准备好的形状；**系数**决定每块积木用多少。固定基函数时，$\Phi_{ij}=\phi_j(x_i)$ 构成 $n\times M$ 设计矩阵，$\theta$ 为 $M\times1$，仍可用线性最小二乘拟合；若连结点位置也要优化，那是额外的模型选择问题，不是同一次普通 OLS 自动解决的。

## 5.12 B-Spline Basis B 样条基与 Local Support 局部支撑

Truncated-Power Basis 的 $(x-\xi)^{3}_{+}$
一旦打开，就会一直影响后面整个区间。B-Spline Basis B 样条基把同一个
Cubic Spline Space 三次样条空间换成一组 Local Support
局部支撑基函数：每个 $B_{j}(x)$ 只在有限区域非零。

$$
f(x)=\sum_{j=1}^{M}\theta_jB_j(x),\qquad M=K+4
$$

> **直觉 Intuition｜换基 ≠ 换模型**
>
> 在相同次数、相同结点及相同边界条件下，Truncated-power 与 B-spline
> 是同一个样条函数空间的不同坐标系统。像同一个地点可以用“经纬度”或“局部坐标”表示；曲线本身没变，表示方式变了。B-spline
> 通常数值更稳定，也更局部。

## 5.13 Validation 验证与 Cross-Validation 交叉验证

模型系数用 Training Data
训练数据拟合；模型复杂度（如多项式次数、结点数）应该用独立 Validation
Data 验证数据选择。如果没有足够数据单独留验证集，就用 K-Fold
Cross-Validation K 折交叉验证。二者的区别只在**验证数据从哪里来**：Validation Set 是一次性留出的一块数据；Cross-Validation 则让每一折轮流充当验证集、再把这 K 次结果平均，等于用更多数据做验证，代价是训练 K 次且各折模型互相关联。

$$
CV_K(c)=\frac{1}{n}\sum_k\sum_{i\in I_k}\left[y_i-\hat f_c^{(-k)}(x_i)\right]^2
$$

公式翻译：$c$ 是候选复杂度，$I_k$ 是第 $k$ 个验证折的样本编号，$\hat f_c^{(-k)}$ 表示“排除第 $k$ 折后重新训练”的模型；平方误差只在被排除的样本上算，最后除以非测试样本总数 $n$。例如补充演示：4 折大小相同、各折 MSE 为 $2,3,1,2$，则 CV MSE 为 $(2+3+1+2)/4=2$；折大小不同时，应按样本数加权。这些演示数字不是题 3 缺失的原始折误差。本节 $K$ 是折数，前面的 $K$ 是内部结点数，含义依上下文区分。

普通随机 K 折适合近似独立、可交换的观测。时间序列应按时间先后验证，预测未来不能用未来数据训练；同一人或门店的重复记录通常应按组划分，避免同一对象同时出现在训练折与验证折。还要记住 $CV_K$ 本身只是泛化误差的一个**估计**，同样带有不确定性：各折误差相互关联，不能把 K 个折 MSE 当成独立样本、直接套 $\hat\sigma/\sqrt K$ 算标准误；K 越大每折样本越少、估计通常越稳但相关也越强，所以差别不大的模型不宜只凭小数点后一位定胜负。CV 用来选模型后，最小 CV 值也可能有选择带来的乐观偏差，仍需最终独立测试。

每一折轮流做 Validation Fold 验证折，其余 K−1
折训练。每个样本恰好被验证一次。预处理也必须只用当前训练折拟合：例如标准化的均值/标准差、缺失值填补值、特征筛选及结点位置，不能先用全数据算好再交叉验证，否则验证折的信息已泄漏进训练流程，CV 误差会过于乐观。选好完整流程与复杂度后，可以用所有 non-test data
非测试数据重拟合；Final Test Set 最终测试集只在最后用一次。

> **易错点 Common Pitfall｜不要反复偷看 Test Set**
>
> 如果你根据测试集表现不断换 degree、knots
> 或特征，测试集就已经参与模型选择，不再是独立的最终评估。

### 题 1：Bias–Variance 与 Prediction Error

在 $x_{0}$ 处真函数 $f(x_{0})=5$，Noise Variance 噪声方差
$\sigma^{2}=1$。Model A 的平均预测 4.5、方差 0.5，所以
$\operatorname{\mathrm{Bias}}=-0.5$，$\operatorname{\mathrm{Bias}}^{2}=0.25$，$\mathrm{Expected\ Prediction\ Error}=1+0.25+0.5=1.75$。Model
B 的平均预测 5.2、方差 1.4，所以
$\operatorname{\mathrm{Bias}}=0.2$，$\operatorname{\mathrm{Bias}}^{2}=0.04$，误差=1+0.04+1.4=2.44。

即使 Model B 的 Training Error
更低，也不能改变这个新数据误差比较：训练误差不是 Bias–Variance
分解里的最终目标。

### 题 2：Cubic Spline 与 B-Spline Basis

区间 $[0,2]$，一个内部 Knot 结点 $\xi=1$，因此 M=K+4=5。课件给
$B(x)=C\phi_T(x)$。在 $x=0.5$
时，$\phi_T=[1,1/2,1/4,1/8,0]^{\top}$，得到：

$$
B(0.5) = [1/8, 19/32, 1/4, 1/32, 0]^{\top}
$$

在 $x=1.5$ 时，$\phi_T=[1,3/2,9/4,27/8,1/8]^{\top}$，得到：

$$
B(1.5) = [0, 1/32, 1/4, 19/32, 1/8]^{\top}
$$

可以看到两端分别有基函数严格为 0，这体现 Local Support 局部支撑。若
$\theta=[1,2,4,6,3]^{\top}$，则因为
$f=\theta^{\top}B=\theta^{\top}C\phi_T$，所以等价的截断幂系数
$\beta=C^{\top}\theta=[1,3,0,0,-4]^{\top}$。在 $x=0.5$，两种表示都给
$f=2.5$。直接核对：$1\cdot\tfrac18+2\cdot\tfrac{19}{32}+4\cdot\tfrac14+6\cdot\tfrac1{32}+3\cdot0=2.5$；截断幂表示则为 $1+3\cdot0.5-4(0.5-1)_+^3=2.5$。

这里 $B(x)$、$\phi_T(x)$、$\theta$、$\beta$ 都是 $5\times1$ 向量，$C$ 为 $5\times5$ 换基矩阵。由 $\theta^\top C\phi_T=(C^\top\theta)^\top\phi_T$，才能得到 $\beta=C^\top\theta$，注意转置不能省。本题在本讲义中未列出 $C$ 的具体元素，上面的基函数值和换基结果按课件给定值使用；若要逐项重算 $C\phi_T$ 或 $C^\top\theta$，需查原课件矩阵，不能凭这些向量猜补。

### 题 3：4-Fold Cross-Validation

| Model           | Mean CV MSE | Train MSE | CV gap |
| --------------- | ----------- | --------- | ------ |
| Degree 2        | 2.30        | 2.10      | 0.20   |
| Degree 5        | 2.30        | 1.30      | 1.00   |
| Degree 9        | 2.50        | 0.45      | 2.05   |
| Spline, 3 knots | 1.85        | 1.15      | 0.70   |

Degree 9 的 Training Error 极低但 CV gap 最大，是最明显的 Overfitting
迹象；按 CV 应选 Spline, 3 knots，因为 Mean CV MSE 最低。若只比较 Degree
2 与 Degree 5，二者 CV MSE 完全相同，通常选更简单的 Degree 2。最终 Test
Set 只用于模型选定后的最后一次评估。
